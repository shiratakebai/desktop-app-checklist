# 桌面应用能力与 QoL 清单

[English](../checklist.md) | 简体中文

本清单列出桌面图形应用在核心功能之外通常需要具备的能力与使用体验，供开发者在规划、设计、实现阶段参考，并在发布前核对。适用于 Windows、macOS 和 Linux，与技术栈无关。本清单不是合规标准，不提供评分或认证。

使用方法、产品类型与 AI 编程 Agent 提示见 [README.md](README.md)；组合场景走查见 [scenarios.md](scenarios.md)；条目所依据的来源见 [references.md](references.md)。

## 阅读路径

全文 250 条不需要一次读完。按下面的顺序，每一遍只看与产品相关的部分：

1. **核心领域中无标签的基线条目**，约 100 条。这是几乎所有桌面应用都该做到的部分。DATA、NETWORK、INSTALL 三个领域整节带标签，不持有用户数据、不联网、不关心分发方式的产品可以跳过，第一遍降到约 70 条。
2. **与产品特征标签对应的条目**，约 30 条中与产品相关的部分。先在 [README.md](README.md) 的产品类型表里确定标签。
3. **适用的条件领域**，51 条中与产品相关的部分。按目录表的"适用"列判断。
4. **QoL 条目**，98 条。可提升使用效率与舒适度，缺失不会导致故障。

使用 Web 技术栈（Electron、Tauri 等）构建，或从 Web 开发转来时，先看 APPEARANCE-07、INPUT-01、INPUT-06、INPUT-24、WINDOW-03 和 SYSTEM-04，以及附录 A 中对应技术栈的部分。

AI 编程 Agent 按 [AUDIT.md](AUDIT.md) 审查时，由 Agent 自行判断适用范围，无需按此顺序。

## 读法

**条目格式**：`ID 标题` · 特征标签 · 基线或 QoL — 期望行为。部分条目附"常见问题"，给出一个典型缺陷。

**基线与 QoL** 用于扫读，不表示优先级：

- **基线**：缺失会导致功能损坏、数据丢失，或在部分系统和设备上无法使用。
- **QoL**：提升效率与使用舒适度。

同一条目对不同用户的分量不同：输入法条目对英文用户属于 QoL，对中日韩用户决定能否使用。优先级由产品自行确定。

**特征标签**：标签提示条目通常在产品具备哪种特征时适用，是否适用以条目正文为准。无标签的条目适用于几乎所有桌面应用。

| 标签 | 产品是否… |
| --- | --- |
| `数据` | 持有用户创作或整理的数据 |
| `文本` | 供用户长时间阅读或编辑文字、代码、日志 |
| `后台` | 关闭窗口后仍在运行 |
| `浮窗` | 平时隐藏，通过热键唤起，用完即关闭 |
| `联网` | 依赖网络服务或账号 |
| `多窗` | 支持多窗口、多标签或多文档 |
| `分发` | 行为取决于分发方式（应用商店、安装程序、便携包、包管理器） |

**领域适用条件**：条件领域在标题下注明适用条件，不适用时整节跳过。

**平台差异**在条目内括注。**技术栈相关的实现细节**按条目 ID 列在附录 A。

**勾选规则**：`[x]` 表示已实现并在真实环境中验证；`[ ]` 表示未实现或未验证；不适用的条目删除或划掉，并注明原因。因排期推迟的条目属于待办，不属于不适用。

## DISPLAY · 显示与布局

- [ ] **DISPLAY-01 系统缩放** · 基线 — 在 100% 至 200% 的系统缩放下，文字清晰，图标不模糊，控件不裁切、不重叠。\
  常见问题：仅在 100% 缩放下开发；用户使用 150% 时按钮文字被截断，设置页底部按钮超出可见区域。
- [ ] **DISPLAY-02 运行时显示配置变化** · 基线 — 系统缩放、显示器连接、分辨率或远程桌面会话变化后，应用无需重启即可适配；需要重启时有明确提示。\
  常见问题：外接显示器断开后，窗口停留在已移除显示器的区域内。
- [ ] **DISPLAY-03 混合 DPI** · 基线 — 窗口在缩放比例不同的显示器之间移动时，布局、菜单、弹窗位置和点击命中区域保持正确。\
  常见问题：在 4K 显示器上，点击位置与指针偏移半个按钮。
- [ ] **DISPLAY-04 窗口尺寸适应** · 基线 — 在声明的最小窗口尺寸和半屏贴靠尺寸下，主要操作仍可访问，溢出内容可滚动或折叠。最小尺寸过大时，窗口无法放入 Windows 贴靠布局。窗口变大时显示更多内容；正文、表单和设置页设置最大宽度。菜单、下拉列表和浮出面板靠近窗口或屏幕边缘时，翻转或平移以完整显示，仍放不下时在内部滚动。窗口缩放跨越布局切换点（例如双栏变为单栏）时，打开的对象、未提交的输入、选中项、焦点和正在播放的媒体保持不变。已打开的菜单和弹出层随之重新定位或关闭，不停留在已消失的控件旁。\
  常见问题：最小宽度固定为 1280 像素，在笔记本上无法与浏览器左右分屏。
- [ ] **DISPLAY-05 内容缩放与界面缩放** · QoL — Ctrl/Cmd + 滚轮、Ctrl/Cmd + 加号或减号缩放内容，Ctrl/Cmd + 0 复位。内容缩放与界面缩放相互独立，侧边栏和按钮不随内容放大。界面缩放可在应用内单独设置；两种缩放偏离默认值时各自显示当前比例并可一键复位。临时缩放与默认值的关系见 SETTINGS-05。
- [ ] **DISPLAY-06 文字放大与长文本重排** · 基线 — 系统或应用放大文字，或遇到长路径、长文件名、较长的译文时，布局保持完整，按钮仍在可操作区域内。因宽度不足而省略的名称、路径和标签可以查看全文。文件名、路径等靠末尾部分区分的名称，宽度不足时从中间省略，保留开头和扩展名。\
  常见问题：德语译文比英文长约 40%，设置页的开关说明全部被截断。
- [ ] **DISPLAY-07 附属界面一致** · 基线 — 菜单、工具提示、对话框、拖动预览和浮动面板使用所在显示器的缩放比例，关键内容可读、可操作；由系统托管的菜单和对话框按系统能力处理。主题一致性见 APPEARANCE-01。
- [ ] **DISPLAY-08 无闪烁、无跳动、操作目标稳定** · QoL — 深色模式下启动时不出现白屏闪烁；异步加载的内容预留占位高度；自动排序、插入新项和后台刷新不改变指针下的操作目标，也不打断正在进行的重命名或编辑（输入的保护见 DATA-03）。上方内容加载完成、展开或窗格宽度变化导致重排时，用户正在阅读的内容保持在原位。\
  常见问题：列表刷新后条目下移一行，用户点中了相邻条目的"删除"。
- [ ] **DISPLAY-09 滚动稳定与高刷新率** · QoL — 60Hz 显示器上滚动稳定、不掉帧；120Hz 及以上的显示器上，滚动和动效不锁定在低帧率。动画和计时按实际经过的时间推进，在不同刷新率的显示器上速度相同，掉帧时不变慢。隐藏时的节流见 TASK-08。
- [ ] **DISPLAY-10 色彩管理与 HDR** · 基线 — 以图像、视频或色彩准确为核心的产品，正确处理内容与显示设备的色彩空间，并在文档中说明支持范围；对不支持的 HDR 内容或色域，提供可理解的呈现或转换方式。界面主题见 APPEARANCE-01，编辑区与画布的配色见 APPEARANCE-02。\
  常见问题：在广色域显示器上导出的图片，在其他设备上显示偏色。

## TYPO · 字体与文本

- [ ] **TYPO-01 系统字体与多文字回退** · 基线 — 默认字体清晰可读；缺少字形时合理回退；中日韩文字、Emoji 和常用符号显示正常；中文环境下"骨、直、门"等字使用中文字形；混合语言的内容按各自的语言信息选择字形，不只按界面语言。\
  常见问题：Linux 上中文显示为方框；Emoji 显示为空白。
- [ ] **TYPO-02 内容字体与字号可调** `文本` · QoL — 编辑、阅读和日志区域可单独设置字体与字号（代码区默认使用等宽字体），设置时有预览，可一键复位；更换字体后，光标、选区和列对齐保持准确。
- [ ] **TYPO-03 界面字体可调** `文本` · QoL — 需要长时间使用的产品允许更改界面字体；更改后菜单、按钮和设置页不被裁切；设置中可区分系统默认与用户自选。继承系统字体已能满足需要时，无需额外提供此选项。
- [ ] **TYPO-04 排版参数** `文本` · QoL — 行高、字间距和连字可按需调整；代码场景可关闭连字，易混淆字符（0/O、1/l/I）可区分。长文阅读和写作区域可以限制行宽（例如窄、中、宽或不限），窗口变宽时每行不随之无限加长。
- [ ] **TYPO-05 字体失效回退** · 基线 — 用户所选字体被卸载后，应用正常启动和显示，设置中标明已回退。\
  常见问题：所选字体不存在时启动崩溃，用户只能手动删除配置文件。
- [ ] **TYPO-06 文本可选择与复制** · 基线 — 路径、错误详情、日志、状态栏数值与版本号可以选择或一键复制。复制成功的反馈保持轻量，例如按钮短暂显示 ✓。\
  常见问题：错误对话框中的文本不可选择，用户只能通过截图报告问题。
- [ ] **TYPO-07 不可见字符可辨认** `文本` · QoL — 编辑文本的产品可显示空格、制表符、行尾和控制字符的标记，显示范围可选全部或只在选区内；标记只影响显示，不改变内容。\
  常见问题：Markdown 行尾的两个空格和混用的 Tab 缩进影响结果，界面上无从定位。

## A11Y · 无障碍

- [ ] **A11Y-01 核心流程可用键盘完成** · 基线 — 不使用鼠标即可完成主要工作流程，不存在焦点进入后无法离开的键盘陷阱。编辑器中 Tab 用于缩进时，提供标准方式将焦点移出编辑区。窗口分为侧栏、编辑区、面板等多个区域时，F6 和 Shift + F6 在主要区域之间循环焦点（macOS 按平台惯例）；已折叠的区域按一致的规则跳过或展开。
- [ ] **A11Y-02 焦点可见、顺序合理、关闭后焦点返回** · 基线 — 焦点位置可见（可以仅在键盘操作时显示焦点框）；Tab 顺序与视觉顺序一致；关闭对话框或菜单后，焦点回到触发它的控件。对话框和新窗口打开时，焦点落在第一个需要操作的位置；持有焦点的对象被删除后，焦点移到相邻项或其容器，不移回窗口的起始位置；用键盘移动焦点时，焦点项完整滚入视野。自动补全、格式化和校验不在用户仍在编辑当前字段时移走焦点。同时显示多个编辑区、分栏或终端时，接收键盘输入的那一个可以辨认，例如其他区域变暗或使用不同的背景。固定的工具栏、状态栏、提示条和浮动面板不完全遮住持有焦点的对象。\
  常见问题：自绘控件没有焦点框，键盘用户无法判断当前位置。
- [ ] **A11Y-03 辅助技术语义** · 基线 — 控件具备名称、角色和状态；无文字的图标按钮有可读的用途说明。带可见文字的控件，其无障碍名称与可见文字一致，以便语音控制用户按屏幕上的文字操作。自定义的树、表格、画布和编辑区提供导航方式或等效操作，虚拟化列表中的对象仍可定位。自绘的列表、树、表格、工具栏和标签栏各占一个 Tab 停靠，内部用方向键移动，Home 和 End 移到首项和末项，键入名称开头可定位到匹配项。树用右方向键展开、左方向键折叠或回到父级；再次进入时回到已选项。导出供他人阅读的文档时，在目标格式支持的范围内保留标题层级、阅读顺序、文字语言、链接和图片替代文字；会把内容转成图片或丢失这些结构的导出方式，在选择前说明。\
  常见问题：屏幕阅读器将整个工具栏读作"按钮、按钮、按钮"。
- [ ] **A11Y-04 状态变化可播报** · 基线 — 保存失败、任务完成、校验错误可被辅助技术获知，且不重复打断；流式输出不逐字播报，完成后的内容可稳定导航和复制。
- [ ] **A11Y-05 对比度与高对比度模式** · 基线 — 文字、焦点指示和关键控件满足产品选定的对比度标准；遵循系统高对比度模式。
- [ ] **A11Y-06 不单独依赖颜色** · 基线 — 成功、失败、选中、差异和图表分类同时以文字、形状或图标表达。说明和错误提示不只用位置、形状、颜色或声音指代控件，同时写出控件的名称。
- [ ] **A11Y-07 遵循减少动态效果设置** · QoL — 系统开启"减少动态效果"后，关闭大面积位移和缩放过渡；信息不只通过动画传达；非必要的自动播放、轮播和持续动态内容可以暂停。
- [ ] **A11Y-08 指针操作负担** · 基线 — 点击目标尺寸足够。拖动类操作（调整面板宽度、排序、移动对象、画布框选）有键盘、菜单或属性面板替代；需要精确数值或远距离日期时，滑块和日期选择器同时接受直接输入。不要求快速、精细或重复的动作；有时限的交互可延长时间。普通按钮在指针松开时触发，按下后移出目标再松开即取消；绘画、演奏等需要按下即响应的操作除外。操作按钮和必要说明不只在指针悬停时出现，键盘焦点和触屏同样能到达；悬停出现的说明在指针移入其中时不消失，遮挡其他内容时可在不移动指针或焦点的情况下关闭（例如按 Esc）。悬停或聚焦时出现的提示，在指针停留于触发元素或提示上、或焦点仍在触发元素上时一直显示，不按固定时长消失。
- [ ] **A11Y-09 多感官等效** · 基线 — 必要的声音、视频和视觉提示按需提供字幕、文字记录或文字替代；仅以声音传达的信息有其他感知途径。配对、登录或初始化流程显示二维码时，同时提供可复制的文本或可手动输入的代码。
- [ ] **A11Y-10 光敏风险与闪烁控制** · 基线 — 应用自身的提示和动效不做大面积快速闪烁；非必要的持续闪动可以停止。\
  常见问题：连接失败时整个窗口以红白交替高速闪烁，开启"减少动态效果"后仍在继续。

## INPUT · 键盘、鼠标、输入法与剪贴板

- [ ] **INPUT-01 平台标准快捷键与键盘布局** · 基线 — 复制、粘贴、撤销、保存、查找、关闭遵循目标平台惯例，按键提示按实际平台显示（macOS 显示 ⌘）；macOS 上 ⌘W 关闭窗口、⌘Q 退出、⌘H 隐藏，三者各自独立。非美式键盘布局下，快捷键按当前布局显示，标点类快捷键经过实测。无法识别当前键盘布局时可手动指定；用 AltGr 输入字符时不触发 Ctrl + Alt 快捷键（Windows）。左右两侧的 Ctrl、Shift、Alt / Option 和 Command 键效果相同。macOS 上提供完整的菜单栏：应用的全部命令都能在菜单中找到，暂不可用的项变灰而不隐藏，单窗口应用也有窗口菜单，退出命令经过应用自己的关闭流程。
- [ ] **INPUT-02 对话框约定** · 基线 — Esc 取消或关闭，Enter 触发默认按钮，Tab 在控件间移动；危险操作的默认按钮不是"删除"。确认对话框的按钮写明对应的动作（例如"保存""不保存""取消"），不只用"是"和"否"；标题、正文和按钮描述的是同一个选择。没有未应用的更改时，取消或关闭对话框不询问是否放弃。流程中途的输入框被取消时，整个操作随之终止，不以空值继续执行。菜单、下拉候选与对话框嵌套时，Esc 和点击外部只关闭最上层；下拉候选打开时 Enter 接受候选而不提交表单；全部关闭后窗口恢复可点击、可滚动。只有按下和松开都发生在外部时，点击外部才关闭对话框、弹出层或菜单。在内部开始的选择或拖动在外部松开，不会关闭它们。
- [ ] **INPUT-03 快捷键可发现** · QoL — 菜单项和工具提示旁显示快捷键；有一处集中列出全部快捷键。Windows 和 Linux 上，菜单项和对话框控件有访问键，同一菜单或对话框内不重复，本地化后仍然可用。
- [ ] **INPUT-04 快捷键可自定义** · QoL — 操作密集的产品允许修改和复位快捷键，并分别提示与本应用其他快捷键的冲突，以及与系统保留组合或其他程序已占用组合的冲突；改键界面显示实际识别到的按键。出厂快捷键避开系统保留组合和常见输入法使用的组合。提供快捷键方案预设（含对标同类产品的方案）和按键反查；依赖小键盘、鼠标中键或特定修饰键的操作在缺少该键时有替代。嵌入的终端、网页或插件面板与主程序使用同一快捷键时，由哪一方响应有明确的规则，并且可以调整。快捷键录制框处于录制状态时，本应用已注册的全局热键暂停响应，当前使用的组合可以被录入。
- [ ] **INPUT-05 命令面板** · QoL — 命令或设置项较多的产品提供 Ctrl/Cmd + K 或 Ctrl/Cmd + Shift + P 类入口，可模糊搜索并直接执行命令、页面和设置项。基本命令同时保留在菜单中。当前不可用的命令仍出现在搜索结果中并说明原因，与菜单中变灰而不隐藏的规则一致。启动器和命令面板按使用频率或最近使用调整结果顺序时，名称或别名的精确匹配排在学习结果之前。单个结果的学习排序可以重置，学习排序也可以整体关闭。常用项列在单独的分组中，其余结果的顺序不随使用改变。结果列表在指针静止时更新或重排，指针下出现的新结果不因悬停成为选中项。跨语言名称的匹配见 LOCALE-05。\
  常见问题：启动器按使用频率重排后，输入用了多年的前缀再按 Enter，打开的是另一个程序。
- [ ] **INPUT-06 输入法组合输入** · 基线 — 组合输入期间不触发快捷键或提交操作；按 Enter 确认候选词不会提交内容；候选窗跟随插入点。输入法开启但未处于组合输入时，Ctrl/Cmd + S、Z 等快捷键照常可用；组合态处理不拦截 Ctrl/Cmd 组合键与 Esc。死键输入（欧洲语言的重音字符）同样不受按键拦截逻辑影响。输入法提交的文字与直接键入一样触发过滤、首项高亮和 Enter 选择。自绘或嵌入的文本编辑区接入平台文本接口，系统表情面板、听写与语音输入、手写输入和系统写作工具可以插入和替换其中的文字。快速键入后立即按 Enter 提交时，提交的内容包含最后键入的字符和输入法刚提交的文字。组合输入开始后，输入框的占位文字随即隐藏。\
  常见问题：在消息输入框中按 Enter 确认候选词，消息被直接发送。
- [ ] **INPUT-07 文本编辑标准行为** · 基线 — 光标移动、Shift 扩展选区、双击选词、三击选行、Ctrl/Alt + 退格删词、Home/End 符合平台惯例；撤销粒度合理。光标移动、删除、选择和长度限制以用户感知的字符为单位，Emoji 序列和组合字符不被截断。文本框允许粘贴，包括密码框。自动更正、智能引号和自动替换可撤销、可关闭，不改写代码、路径和凭据。编辑区域中的链接，单击只定位光标，Ctrl/Cmd + 点击或明确的打开命令才跳转；只读视图中可单击打开。可就地改名的对象（列表项、树节点、表格单元格）按平台惯例进入编辑（Windows 为 F2，macOS 为 Return），Enter 确认，Esc 放弃修改并恢复原值。
- [ ] **INPUT-08 右键菜单** · QoL — 对象上提供相关操作；可用键盘打开（Shift + F10 或菜单键）。在已选中的对象上打开时，命令作用于整个选区。在未选中的对象上打开时，命令只作用于被点的对象，该对象有可见的标示（Windows 通常改为选中它，macOS 通常保留原选区并给它加轮廓）。多选时菜单写明作用的对象数量。右键菜单中的命令在菜单栏、工具栏或对象上的按钮中也有入口。
- [ ] **INPUT-09 拖入** · 基线 — 接收支持的文件和对象，悬停时高亮落点；拖入不支持的内容时有反馈；同一任务始终有非拖放的入口。按产品需要分别处理已有文件路径、内存中的图片、虚拟文件和延迟生成的文件；取消拖放时有反馈。拖入会立即发送给他人或上传到共享位置、且无法撤销时，放下后先确认。拖动过程本身见 INPUT-21。\
  常见问题：从文件管理器拖入文件可用，从邮件客户端拖入附件无响应。
- [ ] **INPUT-10 剪贴板格式与生命周期** · QoL — 按内容提供含义一致的剪贴板格式（纯文本、富文本、图片、文件对象），并实测接收方获得的格式。普通复制的内容在来源窗口关闭或应用退出后仍可粘贴。剪贴板同时含多种表示（矢量与位图、本地文件与网络原件）时，说明默认选用哪一种，可改为每次询问；需要联网取回原件的选项默认关闭并标明。编辑区域提供粘贴为纯文本，快捷键遵循平台惯例（Windows 和 Linux 常用 Ctrl + Shift + V，macOS 常用 ⌥⇧⌘V）。在终端、命令控制台等粘贴后可能直接执行的位置，粘贴多行或末尾带换行的内容时，执行前可检查和取消。敏感内容按 PRIVACY-07 说明的期限处理。
- [ ] **INPUT-11 多选与批量操作** · QoL — 列表支持 Shift / Ctrl（macOS 为 ⌘）多选和全选，并标明"全选"的范围是当前页、筛选结果还是全部数据；批量操作前可预览影响范围，替换类操作可预览前后差异；部分失败后列出成功项与失败项，可仅重试失败项。跨页或筛选后仍保留的选中项显示总数，说明其中包含当前看不见的对象，可一次清除；批量编辑时，取值不一致的属性显示为混合状态，只统一应用用户改过的属性。
- [ ] **INPUT-12 触控板、触摸屏、手写笔与鼠标附加键** · QoL — 触控板平滑滚动、双指缩放和惯性滚动正常；指针位于横向标签栏或宽表格上时，滚轮可横向滚动；触摸屏点击目标尺寸足够；鼠标侧键执行前进和后退，中键关闭或新建标签。遵循系统的滚动方向、滚动速度和双击间隔设置；滚轮经过数字框或下拉框时不意外改变其值。绘画、标注等依赖手写笔的产品，检查压感、笔按钮以及笔与触控之间的切换；设备仅被识别为鼠标时，提供诊断信息。压感缺失或多显示器下笔尖与指针错位时，可切换手写笔输入接口并校正映射区域。\
  常见问题：Windows 上触控板双指滚动按固定步长跳动。
- [ ] **INPUT-13 拖出** · QoL — 应用内的图片、生成的文件和导出项可直接拖到桌面、文件管理器或聊天窗口。拖到文件管理器得到的文件，本应用可以再次打开。拖到文本位置时得到标题、链接等可读内容，不是内部标识。
- [ ] **INPUT-14 以撤销代替确认** · QoL — 高频且可逆的操作（归档、移除、关闭标签、切换配置）立即生效，并提供 Ctrl/Cmd + Z 或短暂显示的"撤销"提示条；仅不可逆操作弹出确认。不可逆操作的确认写明作用对象的名称，作用于多个对象时写明数量。退出和"全部关闭"这类一次结束多项工作的操作，可设为确认后或按住快捷键才执行，可只对键盘触发生效；有未保存更改时，该确认与 DATA-03 的提示合并为一次。撤销范围与历史规则见 DATA-04。以撤销提示代替确认时，永久删除、发送等不可逆的部分在提示消失后才执行。\
  常见问题：每次删除都弹出确认，用户习惯性点击"确定"，误删时也同样确认。
- [ ] **INPUT-15 模态窗口与抽屉的误触保护** · QoL — 用户已在弹窗或侧边抽屉中输入内容时，误点背景遮罩或误按 Esc 后，提示确认或保留草稿。
- [ ] **INPUT-16 智能粘贴** `文本` · QoL — 粘贴剪贴板中的图片时直接插入为内嵌图片或附件；选中文本后粘贴 URL 时生成链接。自动转换可撤销。
- [ ] **INPUT-17 浏览与激活分离** · QoL — 用方向键在列表、标签和预览间浏览时，不触发不可逆或有外部副作用的操作；预览随选择加载时，不阻塞继续浏览；加载延迟或流量开销明显时，改为按 Enter 或空格显式激活。连续浏览时在同一位置预览，开始编辑或显式保留后才固定为常驻标签；用 Esc 退出浏览或临时查找时，回到浏览前的选择和阅读位置。
- [ ] **INPUT-18 输入约束与就地纠错** · 基线 — 表单说明必填项和格式要求；校验错误定位到具体字段并给出修正方式；修正时保留其他已填的有效输入。格式说明和示例在开始输入后仍可见，不只写在占位符中；同一流程中已填写的信息在后续步骤可带入，返回上一步再前进时已填内容保留。以尺寸、坐标、时长等数值为主的产品，数值框接受简单算式和单位（例如 `10cm + 3in`），无法计算时就地提示并保留原值。格式错误在离开字段或提交时提示，不在输入尚未完成时报错。自动格式化（例如插入分组符号）不移动插入点。分段输入框只在一段填满后才自动跳到下一段。\
  常见问题：填完十个字段后只弹出"参数无效"，关闭弹窗后整个表单被清空。
- [ ] **INPUT-19 可辅助完成的身份验证** · 基线 — 登录和验证流程接受凭据管理器的自动填充、粘贴完整密码和验证码；分格的验证码输入框接受整段粘贴。密码输入框可以切换显示明文，切换控件可用键盘操作。密码和 PIN 输入框获得焦点且大写锁定开启时，旁边显示提示，大写锁定关闭后提示随即消失。\
  常见问题：六位验证码分成六个输入框，粘贴只填入第一位，用户只能逐位抄写。
- [ ] **INPUT-20 拼写检查与词典** `文本` · QoL — 面向自然语言写作的区域按所选语言提供拼写检查；可关闭、可选择词典、可管理个人词汇。校对语言与界面语言相互独立；用于多语言写作的产品，可同时启用多个词典，或为文档、段落、选中文字指定语言。\
  常见问题：英文界面下输入另一种语言，所有词都被标红，设置中既不能换语言也不能关闭。
- [ ] **INPUT-21 应用内拖动的过程与结束** · 基线 — 拖动对象、分隔条或列宽时，按 Esc 取消并回到拖动前的状态；指针移出窗口或经过嵌入的网页后松开、切换到其他应用、系统取消触摸时，拖动都会结束，松开指针时不触发下方的控件。拖到可滚动区域边缘时自动滚动；放下前可辨认结果是移动还是复制，并可按平台惯例用修饰键切换；放下后结果保持选中。选中文本、标签页和面板的拖动移动可关闭，或改为需要按住修饰键才生效。拖动经过折叠的树节点、文件夹或标签并稍作停留时，目标展开或切换到前台。移动对象的拖动在目标确认接收后才从来源移除。目标拒绝、用户取消或在窗口外松开时，来源保持不变，拖动高亮全部清除。\
  常见问题：在嵌入的网页预览上松开鼠标后，面板宽度仍随指针变化，窗口其他部分不响应点击。
- [ ] **INPUT-22 提交型输入框的发送键可选** · QoL — 聊天、评论、对话等输入多行后提交的输入框，Enter 发送与 Enter 换行可切换，另一组合键（Shift + Enter 或 Ctrl/Cmd + Enter）执行相反动作；默认值遵循平台和产品类型惯例；该项不随"重置全部快捷键"复位，或在重置时说明是否一并重置。输入法组合态下的 Enter 见 INPUT-06。\
  常见问题：从另一款聊天软件切换过来后习惯性按 Enter 换行，半句话被发了出去。
- [ ] **INPUT-23 改变输入结果的模式持续可见** `文本` · QoL — 改写、修订记录、宏或操作录制等会改变按键或编辑结果的模式，开启期间在编辑区或状态栏持续标明，可以从标记处直接退出。改写模式下插入点的外观与插入模式不同。Insert 等容易误触的模式切换键可以停用。只读、筛选和采集状态分别见 FILE-08、FIND-01 和 MEDIA-04。\
  常见问题：修订记录按钮开与关的外观相同，用户改完几处才发现修订没有被记录。
- [ ] **INPUT-24 编辑命令作用于焦点所在的区域** · 基线 — 剪切、复制、粘贴、删除、全选和撤销，无论从菜单、快捷键、工具栏还是右键菜单触发，都作用于当前持有键盘焦点的区域。焦点位于文本框（包括重命名框、搜索框和检查器中的输入框）时，这些命令作用于其中的文字，不作用于列表或画布中的选中对象。打开多个窗口时，菜单栏命令作用于当前活动窗口及其选区，菜单项的可用和勾选状态随焦点和活动窗口更新。应用级快捷键不抢占编辑区中的复制、粘贴、撤销和方向键，一次按键只执行一个命令。浮窗、托盘应用的面板和隐藏了菜单栏的窗口中，文本框的编辑快捷键同样可用。撤销的范围见 DATA-04。实现要点见附录 A。\
  常见问题：在检查器的名称框中按 Delete 删除一个字符，侧栏中被选中的项目被移入回收站。

## WINDOW · 窗口

- [ ] **WINDOW-01 位置与尺寸恢复** · 基线 — 记住窗口尺寸、状态和位置，并按平台允许的方式恢复；显示器移除或缩放变化后，窗口回到可见区域。在 Wayland 等由窗口管理器决定位置的平台上，应用不设置绝对坐标，由系统保证窗口可访问。首次启动的默认窗口尺寸适应当前显示器。查看器随内容尺寸自动调整窗口的行为可以关闭。用户手动调整过的窗口尺寸不被下一个对象改写，自动调整也不使窗口超出可见区域。反复启动后，窗口的位置和尺寸不逐次偏移。
- [ ] **WINDOW-02 窗口状态恢复与系统窗口管理** · 基线 — 最大化和全屏状态按平台规则恢复；退出全屏后位置合理；支持贴靠布局、虚拟桌面、macOS 全屏空间和 Linux 平铺窗口管理器。自绘标题栏保留双击最大化、边缘拖动调整大小，以及 Windows 11 悬停最大化按钮时显示的贴靠布局菜单。使用自绘标题栏的窗口最大化后，标题栏按钮延伸到屏幕边缘，指针移到屏幕右上角即可命中关闭按钮。以最大化状态退出后再次启动，取消最大化时回到此前的常规尺寸和位置。\
  常见问题：改为自绘标题栏后，Windows 11 的贴靠布局菜单不再出现。
- [ ] **WINDOW-03 关闭、最小化与退出行为明确** `后台` · 基线 — 关闭当前窗口、关闭最后一个窗口、后台任务和退出应用各自的结果可预期，并符合平台惯例：macOS 上关闭窗口后应用通常继续运行，Windows 和 Linux 上通常随之退出；macOS 应用也可以选择在最后一个窗口关闭后退出。关闭窗口后继续运行的产品，在首次关闭时给出提示，并提供"关闭窗口即退出"选项。退出被用户取消或因保存失败而中止时，应用回到完整可用的状态，存储和同步不在中途被关闭。从菜单、托盘、Dock 和快捷键几乎同时发出的退出请求只执行一次退出流程。退出的误触确认见 INPUT-14。明确退出后，应用启动的辅助进程和采集任务随之结束（见 COMPONENT-03）。\
  常见问题：用户以为应用已关闭，实际仍在后台运行；再次启动时因实例已存在而没有窗口出现。
- [ ] **WINDOW-04 多窗口与多实例规则** `多窗` · 基线 — 按产品需要选择单实例或多实例（多项目或多身份隔离可能需要独立实例）；窗口或实例之间的数据、焦点和打开行为有明确规则，配置不相互覆盖。稳定版与测试版、不同安装位置的版本并存时，实例识别、配置、数据和外部打开的路由同样有明确规则。关闭一个主窗口不连带关闭其他主窗口；文档级对话框只阻塞所属文档。
- [ ] **WINDOW-05 再次启动与外部打开的路由** · 基线 — 再次点击应用图标或从外部打开文件时，转到正确的窗口并定位到目标对象。应用尚未启动时收到的打开文件、深度链接或命令行请求，在加载完成后执行，不被上次会话的恢复覆盖。快速用户切换或多个用户同时登录时，单实例锁、本机端口和锁文件按用户会话隔离，各用户的实例互不阻塞，也看不到对方的内容。持有列表或队列的产品，从外部打开或拖入对象时，替换当前、追加到列表还是另开窗口可设定，不默认替换当前列表。单实例通道或本机端口建立失败、上一实例尚未退出时，再次启动仍出现窗口并说明原因，提供结束残留进程的入口。实现要点见附录 A。\
  常见问题：从外部打开文件时启动了第二个实例，两个实例相互覆盖配置。
- [ ] **WINDOW-06 工作区与视图上下文恢复** `多窗` `数据` · QoL — 恢复标签页、布局和上下文。切换标签、从详情返回列表或重启后，保留滚动位置、搜索词、筛选、排序、列宽与列序、选中项、树展开状态和光标位置；对象已不存在时定位到相邻位置；缺失的文件不阻止启动。查看器类产品根据任务和隐私预期决定恢复哪些内容以及何时恢复。恢复撤销历史、光标和折叠前，先确认文件在关闭期间未被外部修改，修改过则不恢复这些状态。在多个对象之间跳转的产品提供按访问路径的后退和前进。启动时恢复上次会话的行为可关闭；恢复导致崩溃或卡死时，可不恢复会话启动（见 HELP-07），会话记录保留。
- [ ] **WINDOW-07 窗口标题包含上下文** · QoL — 标题包含文档名或当前对象，未保存时有标记（macOS 为关闭按钮中的圆点，其他平台通常为 `*` 或 `●`）；多个窗口在 Windows 的 Alt-Tab 和 macOS 的"窗口"菜单与调度中心中可区分。未命名的对象以内容的开头作为标题，几个未命名对象可相互区分。
- [ ] **WINDOW-08 不抢占焦点** · QoL — 后台任务完成、更新就绪或重连失败时，不将窗口切换到前台，尤其不在用户于其他应用中输入时弹出窗口并接收回车；其他应用全屏或演示时不弹窗；改用系统通知或任务栏 / Dock 状态提示。用户从外部追加对象到列表时，是否切换到前台可选。
- [ ] **WINDOW-09 窗口置顶** `浮窗` · QoL — 对照阅读、悬浮工具和小窗模式下可一键置顶，置顶状态有可见标识，可取消。
- [ ] **WINDOW-10 快速唤起与焦点归还** `浮窗` · QoL — 按下热键后窗口立即出现；按 Esc 关闭；关闭后焦点回到用户之前使用的应用；反复唤起和关闭不累积进程或内存。把选中内容送回之前的应用时，目标不接受模拟按键（远程桌面、虚拟机、部分自定义控件）或取不到插入点时，内容仍在剪贴板中可手动粘贴；热键的修饰键不残留到目标应用。为插入或读取文字而临时写入剪贴板的功能（文本展开、取词、把结果送回原应用），插入成功后恢复用户原有的剪贴板内容，包括图片和文件等全部格式。临时写入的内容带有平台的临时标记，剪贴板历史工具不予记录。出现位置与再次唤起见 WINDOW-13。热键失效时的替代入口见 SYSTEM-11。\
  常见问题：翻译浮窗关闭后焦点停留在桌面，用户需再次点击原编辑器才能继续输入。
- [ ] **WINDOW-11 关闭最后一个标签** `多窗` · QoL — 连续按 Ctrl/Cmd + W 关闭到最后一个标签时，回到空工作区或欢迎页（可配置），再次按下不会退出整个应用。
- [ ] **WINDOW-12 从属窗口的位置与层级** · 基线 — 对话框、设置和详情等从属窗口出现在所属窗口所在的显示器上，位于所属窗口之上；切回或还原所属窗口时一并显示；所属窗口关闭时一并关闭，或按明确规则保留。警告和确认对话框每次出现在所属窗口的标准位置，不沿用上次被拖开的位置。\
  常见问题：模态对话框位于主窗口后方，主窗口不响应点击，用户误以为应用已无响应。
- [ ] **WINDOW-13 浮窗的出现位置与再次唤起** `浮窗` · QoL — 浮窗在当前虚拟桌面上出现，出现在哪个显示器（指针所在、活动窗口所在或主显示器）和位置可选，可复位；出现时不打断唤起前前台应用中正在进行的重命名或组合输入；失焦时自动隐藏，固定（见 WINDOW-09）后常驻，再按唤起热键隐藏；再次唤起时，上次的输入和所在层级按可配置的规则保留或复位，例如隐藏超过一段时间后回到初始状态。面向短输入的浮窗可以指定唤起时使用的输入法或键盘布局，关闭后还原为唤起前的输入源。\
  常见问题：启动器固定出现在主显示器，用户正在副显示器上工作，每次唤起都要转头去找。
- [ ] **WINDOW-14 标签页的排列与找回** `多窗` · QoL — 标签超出一行时，所有标签仍可到达（滚动、换行或列出全部标签），当前标签始终可见。新标签插入的位置，以及关闭标签后激活哪一个，规则可预期并可设置。固定的标签与普通标签可区分，不被"关闭其他标签"关闭。标签可以移到新窗口，也可以并入其他窗口。最近关闭的标签和窗口可以按关闭顺序重新打开。\
  常见问题：打开几十个标签后，当前文件的标签被挤出可见区域，只能逐个切换去找。

## APPEARANCE · 外观

- [ ] **APPEARANCE-01 主题与运行时切换** · 基线 — 支持浅色、深色和跟随系统；系统主题切换后在运行中生效，范围包括标题栏、滚动条、右键菜单、原生对话框、弹窗遮罩、托盘图标及所有附属界面。\
  常见问题：主界面已切换为深色，设置对话框仍为浅色。
- [ ] **APPEARANCE-02 内容主题独立** `文本` · QoL — 编辑区或画布的配色可与界面主题分开设置。
- [ ] **APPEARANCE-03 遵循系统视觉惯例** · QoL — 遵循系统强调色、字体渲染、圆角和控件样式；自绘或跨平台控件同样遵循所支持平台在关键操作、焦点、主题和窗口方面的惯例，与平台的差异是有意且一致的。使用半透明窗口、面板或浮层的产品，在系统开启降低透明度后改用不透明背景，运行中切换即时生效。自绘或跨平台框架的滚动条遵循系统"始终显示滚动条"的设置，显示时与背景有足够对比并可拖动。确认与取消按钮的左右顺序遵循目标平台和桌面环境的惯例。
- [ ] **APPEARANCE-04 布局密度** · QoL — 信息密集的产品提供紧凑和标准两档密度。\
  常见问题：改版增加留白后，小屏用户可见的内容减少，且没有紧凑选项。
- [ ] **APPEARANCE-05 面板可调整、可复位** · QoL — 面板可拖动调整宽度、折叠和重排，双击分隔线恢复默认宽度；折叠或隐藏的面板在界面上留有可见的找回入口，例如工具栏或标题栏中的开关、窗口边缘的面板标签，或"显示"菜单中附带快捷键的命令，不只依赖快捷键、悬停才出现的按钮或需要精确拖动的窄边；菜单中提供"重置窗口布局"，重置布局不影响文档和草稿。分隔条可用键盘聚焦和调整；面板折叠后再展开，回到折叠前的宽度；窗口临时缩小导致面板变窄时，不改写用户保存的布局。宽表格固定表头和标识列，可选择显示的列。隐藏的菜单栏在 Windows 和 Linux 上可按 Alt 临时显示。专注模式与命名布局见 APPEARANCE-08。
- [ ] **APPEARANCE-06 自定义配色的安全性** · QoL — 允许自定义配色时，关键状态仍可区分；提供一键恢复默认配色，避免配色错误导致界面无法辨认。可能使界面无法辨认的更改（应用外来主题、调整配色或缩放）可以先预览。应用后在限定时间内未确认的，自动回到更改前的状态。
- [ ] **APPEARANCE-07 隐藏 Web 运行时痕迹** · QoL — 使用 Web 技术栈的产品：在按钮、标签、导航等非正文区域拖动鼠标时不出现文本选中高亮，需要带走的信息仍可复制（见 TYPO-06）；误触刷新不丢失页面状态；外部链接在系统浏览器中打开，主窗口不跳转到外部网页；生产环境不显示开发者右键菜单。刷新和打印属于业务功能时照常保留。实现细节见附录 A。
- [ ] **APPEARANCE-08 专注模式与命名布局** · QoL — 以阅读或编辑为主的产品提供一键隐藏侧栏、工具栏和状态栏、只保留内容区的模式（专注或阅读模式）；退出后各面板回到进入前的状态，不改写已保存的布局。面板较多的产品可将当前布局保存为命名的工作区，并在工作区之间切换，切换时不丢失未保存的内容。

## SETTINGS · 设置

- [ ] **SETTINGS-01 入口可发现、按任务分组、默认可用** · 基线 — 设置入口位于惯例位置（macOS 为应用菜单中的"设置…"，快捷键 ⌘,；其他平台为齿轮图标或菜单项）；按用户任务而非代码模块分组；每项附一句说明。使用默认配置即可完成第一个有价值的任务。设置项较多时，常用项默认显示，高级参数和开发者选项收在"高级"分组或由一个开关显示；切换显示范围不改变已设置的值。某项设置会使其他功能不可用，或明显增加内存、磁盘、处理时间等资源开销时，在该设置旁说明具体后果。再次打开设置时转到已打开的设置窗口，不另开一个。命名模板、日期格式等决定输出结果的设置，旁边显示按当前值生成的示例。
- [ ] **SETTINGS-02 设置可搜索** · QoL — 设置项超过一屏时提供搜索，并支持常见同义词（例如搜索"字号""DPI""代理"均可找到对应项）。可筛选出偏离默认值的设置并逐项恢复。搜索范围包括设置的说明、可选值，以及子页面和对话框中的设置，命中位于对话框中时在其入口上标出；默认收起的高级设置被搜索命中时直接显示并标明，或提示另有高级设置匹配。每项设置有不随界面语言和版本变化的标识，可查看、复制和搜索。通过这一标识或链接可以直接打开对应的设置，便于帮助文档和支持对话引用。跨语言名称的匹配见 LOCALE-05。
- [ ] **SETTINGS-03 生效时机明确** · 基线 — 即时生效的开关不附带多余的"保存"按钮；需要确认或重启才生效的设置有明确标注。开关显示的状态与实际一致：异步生效期间显示"生效中"，启用失败时显示"未能生效"。反映系统设置或其他程序状态的开关显示当前的实际值，在外部更改后随之更新。
- [ ] **SETTINGS-04 持久化可靠、手动编辑容错** · 基线 — 采用原子写入，存放在符合平台和分发方式的位置（各平台的位置见附录 A）。设置无法写入（目录只读、磁盘已满、文件被占用）时，在修改的当时报告失败和路径，不在重启后静默回到旧值。同时运行的多个实例共用设置时，一个实例退出不覆盖另一个实例已经保存的修改。提供可手动编辑的文本配置时，若用户写入语法错误，启动时报告出错的行和列并以默认值运行，原配置文件保持不变。无论通过界面、手动编辑、命令行还是导入写入，设置值不合法（类型不符、超出范围或不在可选值中）时，报告出错的设置项，并按默认值或最近一次有效值运行。界面显示的值与实际生效的值一致，保存的原值不被静默改写。\
  常见问题：断电导致配置文件只写入一半，下次启动直接崩溃。
- [ ] **SETTINGS-05 作用域明确** · QoL — 存在全局、工作区、项目、账号或文件类型等多级设置时，覆盖关系可见。查看或播放中临时调整的缩放、音量、速度不改写保存的默认值；是否沿用到下一个对象可设置。
- [ ] **SETTINGS-06 配置可导出、可编辑、可同步** · QoL — 有迁移需求的产品提供配置导出或备份方式；可读的文本配置便于手动编辑和纳入版本控制；设置页提供"打开配置 / 日志 / 数据文件夹"按钮；导出默认不含密钥。提供跨设备同步时，机器相关值（本地路径、设备选择、显示布局）、平台专属快捷键和凭据不随同步覆盖。文档或工程中保存的打印机、视图位置等机器相关设置，在其他计算机上或由其他用户打开时默认不生效。
- [ ] **SETTINGS-07 按类别重置** · 基线 — 重置前说明范围；重置偏好设置不删除用户数据。重置或清除配置前自动保留上一份，可回退。"不再显示"只用于例行提示，涉及风险的确认始终显示；被隐藏的提示可在设置中一次恢复。恢复操作说明恢复到哪一个状态：本次编辑前、上次保存的配置，还是出厂默认值；撤销未应用的更改与恢复默认值是可区分的两个入口。用户改过的内置模板、样式和预设可以单独还原为原始版本，并与用户自建的对象区分开。
- [ ] **SETTINGS-08 升级迁移** · 基线 — 升级后保留有效设置；已失效的选项有说明和替代方案。新版本改变对旧文件的解释（单位、DPI、函数和计算规则）时，打开旧文件先说明差异，保留原来的解释或提供转换方式，不静默改变尺寸、数值和计算结果；新大版本使用独立配置时，首次启动可从上一版本导入设置和扩展，用户自装的扩展、模板和脚本升级后保留。

## LOCALE · 语言与地区

- [ ] **LOCALE-01 界面语言** · 基线 — 默认跟随系统语言，可手动切换且无需重新安装；缺少译文时回退到英文，不显示空白或字符串键名。翻译覆盖面较大的专业产品，可以分别选择是否翻译界面标签、提示文字和新建对象的默认名称。语言列表中，每种语言以其自身的文字书写（例如 Deutsch、日本語），不用国旗代表语言。切换界面语言后，托盘菜单、跳转列表、通知和系统菜单栏中由应用提供的文字一并更新，不能即时更新的部分说明需要重启。提供多语言名称的应用，在文件管理器、Dock、开始菜单和通知中按系统语言显示对应的名称。
- [ ] **LOCALE-02 翻译完整** · 基线 — 关键流程、错误信息和设置项无漏译，不使用拼接句式；复数、零数量和量词按目标语言的规则处理。后续版本新增的功能、高级设置的说明、错误对话框和搜索结果同样在翻译范围内；界面不出现未替换的占位符。语言列表标明翻译不完整的语言及其完成程度。
- [ ] **LOCALE-03 日期、数字、单位与货币** · 基线 — 显示格式遵循所选地区；一周的起始日正确。区域格式与界面语言分开：日期时间格式默认跟随系统的区域格式，可在应用内单独更改；纸张尺寸和长度单位的默认值同样按地区取。支持地区纪年（日本元号、民国纪年、佛历）的产品，纪年换算不硬编码在程序中，改元后无需发布新版本即可显示新纪年。输入和导出格式的含义明确。计数、字节数、金额等较长的数字，显示时使用所选地区的分组符号和分组方式。年份、版本号、编号和端口号等标识不插入分组符号。数字输入按所选地区解析小数和分组符号，`1,5` 不会被静默解析为 `15`。粘贴到数字输入框的数字带有分组符号或空格时，照常接受。复制数值时可以得到不含分组符号的值。按格式、列宽或单位换算显示的数值精度低于存储值时，可以查看和复制完整值。复制和导出到交换格式时使用显示值还是存储值，界面有说明，导出时可以选择。按显示精度改写存储值的选项，启用前说明作用范围以及能否恢复。
- [ ] **LOCALE-04 时区** · 基线 — 涉及时间的产品区分本地时间、固定时区和跨地区时间；夏令时切换产生的重复或不存在的本地时间有明确处理。时区规则（夏令时起止、时区偏移）跟随系统或可独立更新，不固定在程序自带的数据库中；地区修改规则后，应用显示的时间与系统时钟一致，不等待程序发布新版本。只有日期的值（生日、截止日）在任何时区下都显示为同一天。系统时区在运行中改变后，已打开界面中的时间和已安排的提醒按新时区重新计算，固定在某一时区的日程保持原定的当地时间。\
  常见问题：地区改为永久夏令时后，系统时钟正确，应用内所有时间偏差一小时。
- [ ] **LOCALE-05 多语言文本处理** · QoL — 换行、分词、排序和大小写转换在目标语言下正确；文件名等列表中的数字按数值排序（`第2章` 在 `第10章` 之前），与系统文件管理器一致。搜索兼容该语言的书写变体，例如中文拼音首字母与繁简体、日文假名、拉丁字母变音符号、全角与半角，以及 Unicode 规范等价的不同编码，从其他系统复制来的名称同样能找到。界面已本地化时，命令、设置和页面等预置对象的搜索同时接受界面语言的名称和英文原名，结果中可看到英文原名。具体支持范围由产品决定。
- [ ] **LOCALE-06 从右至左书写** · 基线 — 支持阿拉伯语、希伯来语的产品，布局镜像、图标方向和双向混排文本正确；文件名和标识符中的双向文本不会因方向控制符掩盖真实名称和扩展名。

## DATA · 数据保护、保存与恢复 `数据`

- [ ] **DATA-01 保存状态可见** · 基线 — 已保存、未保存、保存中、保存失败四种状态可区分。新建后未编辑的文档，以及仅被程序自动重排的文档，不标为未保存，关闭时不询问。
- [ ] **DATA-02 自动保存与崩溃恢复** · 基线 — 未持久化的编辑按明确策略自动保存；进程异常退出后，下次启动可恢复，并说明可能丢失的时间范围。恢复的内容与外部已更新的文件冲突时，保留双方并供用户预览后选择。恢复的内容附带编码、换行符和目标路径。自动写回原文件的产品，可在开始编辑前创建副本并转到副本上编辑，或以模板、只读方式打开；当前编辑和自动保存写入的是哪一份清楚可见。有多项可恢复的内容时，集中列出并显示来源和时间，可以全部恢复、全部放弃或逐项选择。恢复的内容沿用原文件的加密和访问保护，恢复后的保存同样受保护；无法保持时说明变化，并保留受保护的原件。\
  常见问题：启用了自动保存，但崩溃后恢复的是三小时前的版本，且没有任何提示。
- [ ] **DATA-03 未保存更改保护** · 基线 — 关闭、退出、切换对象、系统关机或应用更新前，处理未保存的更改。后台刷新、自动排序和同步不丢弃用户正在进行的重命名或编辑。退出或一次关闭多个对象时，未保存的对象集中列在一个对话框中，可全部保存、全部放弃或逐个处理。
- [ ] **DATA-04 撤销与重做的作用对象** · 基线 — 可撤销操作的范围清晰；保存后仍可撤销；存在多个编辑区或多个窗口时，Ctrl/Cmd + Z 作用的对象明确，焦点变化不会导致误改其他位置。撤销与重做的入口写明对应的动作；撤销结果不在可视区时，视图移到该处。撤回导入、批量替换或自动生成的一批改动时，不连带撤回用户在此期间手动做出的修改。剪切、复制、粘贴等其他编辑命令的作用对象见 INPUT-24。
- [ ] **DATA-05 历史版本与备份** · QoL — 需要时提供可查看、可恢复的历史版本或备份，并说明保留期限。同步不是备份：错误的内容同样会被同步到所有设备。备份是一致的副本，可在空目录中恢复出数据和附件；运行中的数据库通过备份接口导出，实现方式见附录 A。历史版本可以与当前版本对比，也可以只取出其中一部分内容，不必整体覆盖当前版本。
- [ ] **DATA-06 安全写入** · 基线 — 写入失败或中断时，原文件保持完好；内存中的内容保留，可重试或另存。替换保存后，原文件的权限和属性保持不变，私密文件不会变成其他用户可读；原文件是符号链接时保存到其目标；有多个硬链接时，保存不会在无提示的情况下断开链接。因大小或数量限制只载入部分内容时，界面明确标示，保存不以部分内容覆盖原文件。"完成后删除源文件"和原地替换类操作先验证产物完整再删除源文件，任务失败或验证失败时源文件保持不动并说明。实现方式见附录 A。\
  常见问题：磁盘空间不足时，保存操作将原文件截断为 0 字节。
- [ ] **DATA-07 外部变化与冲突** · 基线 — 文件被其他程序修改、移动或删除，或远端存在并发修改时：没有未保存的改动则自动重新加载；存在冲突则提示用户并保留两个版本。文件被其他程序以"写入临时文件后替换"的方式保存、被重命名或存储断开重连后，监听仍然有效；遗漏事件时可手动刷新或重新扫描。系统的文件变化通知不可用（监听数量达到系统上限、网络盘不支持通知）时，告知用户并改为定期扫描或手动刷新。冲突策略按数据类型分别检查，文本、附件、画布和配置可能需要不同的处理方式。多设备同步时，每台设备有用户可改的名称，同步记录和冲突副本用这个名称标明来源。与其他程序共用的配置或数据文件只改写自己的项，保留不认识的字段和注释；界面说明哪些设置是共享的。草稿只属于所在对象，在通知中快速回复写下的内容不会出现在其他对象中；云端草稿同步不覆盖本机正在输入的内容。
- [ ] **DATA-08 导入导出与数据可迁移** · 基线 — 提供适合长期保存和迁移的导出格式，优先使用通用或有公开文档的格式；支持批量导出；尽量覆盖全部用户数据，无法导出的内容、外部依赖和有损部分事先说明。"保存完整工程"与"导出交换格式"可以并存，界面标明哪一种保留完整状态；导出结果至少在干净环境中打开验证一次。在线服务停止或在线功能移除前，应用内说明受影响的范围、取回数据的截止时间和导出入口。导出结果包含附件本身，不只留下指向已停止服务的链接；保存在本机、无需服务授权的资料照常可用。导入时的合并与类型识别见 DATA-18。
- [ ] **DATA-09 数据位置透明、可迁移** · QoL — 用户可以查到数据存放位置；有迁移需求时允许选择目录或提供迁移工具。采用便携分发时，程序与数据放在一起，便携副本在多台计算机或多个用户间使用时，可按计算机或用户区分数据文件；受管安装的数据存放在用户目录。用户选择的数据、缓存或录制目录所在的文件系统不适合时（FAT32 的单文件大小上限、网络盘），在选择时就告知。磁盘空间不足或目录不可写时给出可操作的提示。说明哪些目录可以放在同步盘中：正在使用的数据库放在 Dropbox 或 OneDrive 中有损坏风险。体积较大的缓存、索引和模型文件显示占用空间，并允许移至非系统盘。可重新生成的缓存和临时文件有清理策略（缓存目录中唯一副本的保护见 DATA-10），崩溃残留的临时文件在下次启动时清理，其中用于恢复的内容在用户处理前保留。只为查看而打开的下载内容存放在临时位置，不留在用户的下载目录。派生数据的重建与孤儿文件的清理见 DATA-15。
- [ ] **DATA-10 大范围删除与迁移的保护** · 基线 — 批量删除的内容进入回收站或可恢复。对同步或共享数据的删除和清空，执行前说明作用于本机、自己的所有设备，还是其他参与者看到的内容。缓存目录中若存有离线修改或未上传附件的唯一副本，清理缓存时按用户数据保护。未能上传的唯一副本所在的文件夹在远端被删除或移动时，本机副本保留或移入回收站，并提示用户。升级时的数据迁移失败可回滚。从声明支持的旧版本升级时，直接完成迁移，或引导先升级到所需的过渡版本；不支持的旧格式明确提示，原数据保持不变。迁移被中断后再次启动，继续完成或回到升级前的状态，迁移到一半的数据不被当作已完成。数据位置不可达时的处理见 FILE-05。
- [ ] **DATA-11 外部资源重新定位** · QoL — 引用外部图片、附件、字体或素材的项目移动到其他目录、磁盘或计算机后，可以重新链接，或按需打包依赖；资源缺失时先请用户定位，保留关联记录。在应用内移动或重命名被引用的资源或文档时，同时更新引用，包括文档之间的内部链接；无法更新时先列出受影响的引用。
- [ ] **DATA-12 数据规模增大后的处理** · QoL — 大文件、长历史记录或海量对象超出当前处理能力时，说明限制，并提供分批处理、只读打开、缩小范围或导出；不出现无限加载；只载入部分内容时的保护见 DATA-06。打开大文件时先给出反馈并显示已可显示的部分，无需等待全部索引完成。
- [ ] **DATA-13 数据文件损坏时的处理** · 基线 — 启动或打开时检测数据库、配置或文档的损坏；不以空默认值覆盖损坏的文件；提供从备份恢复或导出可读部分的途径；不进入反复崩溃的循环。由更高版本写入、当前版本无法识别的数据不按损坏处理：不隔离、不清理、不用较旧的备份覆盖，而是说明需要升级并保留原数据，之后的自动保存同样不改写这些数据。用旧版本打开新数据的处理见 INSTALL-05。派生数据的重建见 DATA-15。\
  常见问题：加载失败后直接写入默认值，用户积累多年的数据被清空。
- [ ] **DATA-14 离开后可发现未完成的工作** · QoL — 带有草稿、未保存修改、发送失败或待同步内容的对象，在列表、树、标签或侧栏中有标记，或集中列在一个入口中，可直接继续或重试；完成或放弃后标记消失。新建后未编辑的空对象不标为未完成。\
  常见问题：在会话 A 中回复写到一半时切换到其他会话，会话列表上没有草稿标记，这条回复最终没有发出。
- [ ] **DATA-15 派生数据与孤儿文件的维护** · QoL — 缓存、索引、缩略图和统计等派生数据可从界面触发重建，重建只读取原始数据，不改写或删除原始数据（恢复入口见 HELP-07）。不再被任何对象引用的附件、备份和缩略图可扫描列出，按类说明位置、占用和风险，清理前可预览，清理结果可恢复（见 DATA-10）。\
  常见问题：换了分词器后对话的统计数字全是旧值，用户找不到重算入口，只能删库重来。
- [ ] **DATA-16 批量变更的预览与模拟运行** · QoL — 同步、批量重命名、批量转换等会改动大量文件的操作，执行前可以预览每一项将发生的变化（新建、覆盖、删除或改名），并可逐项排除或调整。首次执行可能覆盖或删除文件的任务之前，提议先模拟运行。预览和模拟运行不写入任何数据，也不推进任务状态。预览之后、执行之前，目标对象或其内容发生变化时，受影响的项停止执行或重新预览；预览之后新出现的覆盖和删除，不沿用此前的确认。删除的保护见 DATA-10。\
  常见问题：新建的镜像同步任务方向设反，第一次运行就用空目录覆盖了源目录。
- [ ] **DATA-17 加密资料的恢复条件与保护范围** · 基线 — 持有加密用户资料的产品，说明恢复备份或换用设备时需要哪些口令、密钥文件、恢复材料、硬件或原账号；加密导出只能导回原账号或原服务时，导出前写明。恢复材料可以单独导出保存，材料丢失后资料无法恢复时，启用加密前说明这一后果。更改口令时，说明旧备份和已导出的恢复材料是否仍能解开资料。恢复过程中，无法解密的原资料保持原样，不被空白数据覆盖。导出明文或交给外部程序打开时，说明产生的副本是明文、存放在哪里、如何清理；应用自己创建的临时副本按说明清理。实现要点见附录 A。\
  常见问题：数据库备份完好，解密所需的密钥却随旧电脑的钥匙串一起丢失；用户以为重新登录即可恢复，最终只剩无法解开的备份。
- [ ] **DATA-18 导入时的合并与类型识别** · 基线 — 导入带有标签、分类或关联资源的对象时，附属信息如何并入本地体系（全部导入、只保留本地已有、不导入、每次询问）由用户选择，默认值可在设置中改回"每次询问"。导入时自动识别字段类型可能改变含义（去掉前导零、截断长编号、把编号识别为日期）时，导入前可查看识别结果，并按列选择按文本、数字或日期以及按哪个地区解释。\
  常见问题：导入 CSV 时邮编被识别为数字，前导零被去掉，导入后无法还原。

## FILE · 文件与资源

- [ ] **FILE-01 平台文件对话框与持久授权** · 基线 — 使用系统的打开、保存和选择目录对话框；记住上次使用的目录；取消时不产生任何变化。沙箱环境下（macOS App Sandbox、Flatpak），最近文件和工作区保存持久授权，而不仅是路径；授权失效时提供重新授权的方式。打开、保存、导入和导出分别记住上次的目录，也可以为某一用途指定固定目录。记住的目录不可达时，回到默认位置。
- [ ] **FILE-02 最近文件** · QoL — 可重新打开最近使用的对象；失效路径有相应处理；列表可清除；接入系统的最近文档和跳转列表。不经"打开"对话框打开的文件（拖放、双击、命令行）同样进入最近文件。常用项可以固定，固定项不随列表容量淘汰。位于暂时不可达位置（网络盘、外置盘）的项标明状态，不被自动移出列表。
- [ ] **FILE-03 路径、字符与命名冲突** · 基线 — 支持 Unicode 用户名、Emoji、空格、长路径、网络路径和符号链接。跨系统同步、导出到目录、解压或批量重命名时，仅大小写不同或仅 Unicode 规范化形式不同（macOS 常见的分解形式与其他系统的组合形式）的文件名不会被静默覆盖，也不会变成两个看起来相同的文件。来自服务器、归档或批处理的文件名按本地规则清洗：非法字符、保留名（CON、NUL）、尾部空格和点、长度限制；清洗后重名时可预览或明确解决。截图、录制、导出等自动命名的产物，默认文件名包含来源和时间，命名模板可配置，同名时自动加序号。显示文件名时，双向控制字符被去除或以可见形式显示，扩展名无法借此伪装。\
  常见问题：在中文用户名目录下安装失败或启动报错。
- [ ] **FILE-04 移动、重命名与删除的反馈** · 基线 — 操作后界面与实际状态一致；删除时优先移入回收站，永久删除或回收站不可用时明确说明；失败时说明原因。应用内撤销与系统回收站是两种独立的恢复途径，分别提供。
- [ ] **FILE-05 网络驱动器、可移动介质与云盘占位文件** · 基线 — 存储断开时应用整体不失去响应，保留用户的工作，并提供重新连接或另存为。云盘中的仅联机文件路径存在但内容需要下载；打开、索引或批量处理这类文件时，不误报文件损坏，不在无反馈的情况下阻塞，不意外触发大量下载。库目录、同步目录或下载目录因外置盘拔出、盘符变化或网络盘未连接而不可达时，区分"未找到"与"已删除"：停止相关任务并提示重新连接或重新定位，不把缺失传播为删除，不新建空库覆盖配置；更换到空的同步目标前，明确是迁移、重新下载还是清空。
- [ ] **FILE-06 在系统中定位** · QoL — 对象支持"在文件管理器中显示"、复制路径和用其他程序打开。"在文件管理器中显示"遵循用户设置的默认文件管理器，或允许指定第三方文件管理器。
- [ ] **FILE-07 编码与格式识别** `文本` · 基线 — 识别文本编码和换行符，无法确定时由用户选择；正确处理 BOM；转换有损时给出提示。
- [ ] **FILE-08 文件锁与残留锁文件** · 基线 — 打开的文件默认不独占锁定，其他程序仍可读取和同步；确需锁定时说明。崩溃后残留的锁文件（`.lock`、`~$` 文件）在下次启动时被识别并清理，不误判为已有实例在运行。文件被其他程序占用时，提示占用者。文件或所在目录只读时，打开后即标明只读及原因；尝试编辑时提供解除只读或另存为的途径。\
  常见问题：崩溃后锁文件残留，应用拒绝启动，用户只能手动找到并删除锁文件。
- [ ] **FILE-09 浏览同目录的相邻对象** · QoL — 查看器和播放器类产品打开单个文件后，可前后浏览同一目录中的同类对象，参与浏览的类型可见可调；到达首尾时停止、循环或进入下一目录由用户选择并有提示；删除或移动当前对象后定位到相邻对象。\
  常见问题：双击打开一张图片后按方向键没有反应，只能回到文件管理器再双击下一张。

## TASK · 任务、响应与资源

- [ ] **TASK-01 冷启动反馈** · QoL — 点击图标后迅速出现窗口或启动画面；产品为启动时间设定目标值，并分别衡量冷启动、温启动和唤起已有实例。首次启动或升级后的一次性准备（建立字体缓存、索引资源）显示进度或说明；启动明显慢于目标时，可查看初始化、载入数据和各扩展的耗时，结果可复制。离线或服务不可达时，启动不等待网络请求超时：本地内容先显示，更新检查、同步等联网工作在后台进行。\
  常见问题：双击图标五秒无反应，用户又点击两次，启动了三个实例。
- [ ] **TASK-02 长操作状态** · 基线 — 显示当前正在执行的操作；无法估计进度时不显示精确百分比；很快完成的操作不闪现加载指示。长任务按接收、验证、处理和交付等阶段报告状态；临时空间需求纳入磁盘空间预检。多步骤任务共用一条总进度，不在步骤之间归零，没有实际进展时不前进；剩余时间在估算稳定后才显示。完成后可直接打开或定位产物。
- [ ] **TASK-03 停止等待、取消任务与撤回结果** · 基线 — 可取消的阶段提供取消操作。请求可能已到达服务器或外部程序，界面停止等待后远端操作仍可能完成；不可取消的提交阶段显示当前状态。取消后哪些中间产物保留、哪些清理，按明确策略处理并告知用户。按钮区分"取消"（恢复原状）与"停止"（保留已完成的部分）。撤回已发出的消息或邮件后，内容回到编辑区。
- [ ] **TASK-04 暂停与继续** · QoL — 下载、转换、同步等任务可暂停和恢复。续传信息在应用重启后保留；恢复前确认远端内容未变化，已变化时明确重新开始。进度和续传信息按说明的间隔写入磁盘，强制结束或断电后最多丢失一个间隔内的进度。
- [ ] **TASK-05 失败重试与幂等** · 基线 — 失败的任务保留上下文；上传、创建、发送、计费等有副作用的操作，处理"远端已成功但响应丢失"的情况，重试不产生重复结果。临时链接过期、镜像失败或服务要求稍后重试时，保留任务目标并说明。提交、发送、创建等操作在完成之前，再次点击或按 Enter 不会再执行一次，触发它的控件显示正在进行。按住提交、发送、删除类快捷键时，命令不随按键的自动重复连续执行。
- [ ] **TASK-06 后台任务入口** · QoL — 用户可找到进行中的任务，查看状态，并选择继续或停止；运行状态说明正在处理的对象和触发原因。退出时仍有进行中的任务，提示并说明后果。任务因等待用户确认而暂停、且窗口不在前台时，通过徽标或通知告知；用户回应后提醒自动撤回。关闭仍有任务在运行的面板、标签或窗口时，可以选择终止任务，或让任务在后台继续。这一选择可以设为默认。停用或删除一条自动规则后，按这条规则进行中和排队的操作随之停止，或说明会继续完成。规则已经施加的效果是否撤销，同样说明。计划任务见 TASK-17。
- [ ] **TASK-07 交互响应** · 基线 — 长操作期间窗口可拖动、可切换视图、可取消；索引、解析、补全或大型任务进行时，输入和光标不出现明显积压，处理不过来时降级运行，界面不冻结。通过辅助功能接口、自动化脚本、系统音频服务或外部命令与其他程序交互时，调用设有超时，不在界面线程上等待。对方无响应时，本应用保持响应，并指出无响应的程序。不设统一的毫秒阈值，使用产品的典型文档和硬件测试。
- [ ] **TASK-08 空闲资源预算** · QoL — 窗口最小化、被遮挡或隐藏时，停止或降低已无必要的活动（动画、画布重绘、高频轮询）；用户要求的持续任务（播放、录制、监控、传输）照常运行。窗口失去焦点但仍可见时（例如在另一台显示器上并排使用），内容照常更新，视频和通话不暂停。后台空闲时 CPU 占用接近零，内存不持续增长；低电量或省电模式下进一步减少非必要活动。资源预算由产品按实际任务确定。图形后端出错时提供诊断或降级入口，是否允许关闭 GPU 加速由产品决定。显卡切换、驱动重置或硬件解码不可用时，保留工作并降级运行。有多块 GPU 时，设置中显示应用当前使用的 GPU 并可改选，改选需要重启时标明。\
  常见问题：一个驻留托盘的轻量工具消耗了笔记本约三成电量。
- [ ] **TASK-09 睡眠唤醒、网络与设备变化** · 基线 — 合盖睡眠数小时后唤醒，或切换 Wi-Fi、VPN 后，连接自动恢复或干净地重置，不连续弹出大量错误；切换音频输出、插拔耳机或摄像头被占用时，回到可选设备或可恢复的状态；设备失效后不按旧的枚举顺序连接到另一台同类设备。系统时间跳变后，超时、重试和持续时间的计算不出现异常，依赖真实时间的验证失败能指出时钟问题。运行期间接入的设备出现在设备列表中，或者可以手动重新扫描。
- [ ] **TASK-10 流式输出的视口行为** · QoL — 内容正在流式生成或滚动输出时，用户向上滚动后停止自动滚到底部，滚回底部或点击"回到底部"后恢复跟随；始终提供"停止"按钮和快捷键，中止后保留已收到的全部内容，不只是已显示的部分；逐字显示等效果只影响显示节奏，可关闭。屏幕阅读器下的行为见 A11Y-04。
- [ ] **TASK-11 过期结果不覆盖当前操作** · 基线 — 先搜索 A 再搜索 B，或连续切换对象和预览时，较早的请求晚返回也不替换当前内容；窗口关闭后不弹出旧操作的结果；切换账号后，旧账号的响应不进入新账号的界面。联想结果尚未按最新输入更新时按 Enter，提交的是当前输入。
- [ ] **TASK-12 长任务中断后的产物** · QoL — 录制、生成或转换被中断后，分别说明主体内容是否可用、附属信息（章节、元数据）是否完整、能否继续处理；说明当前输出格式在中断时的保护范围。
- [ ] **TASK-13 工作期间的资源控制** · QoL — 索引、转换、压缩、推理等密集任务运行时，用户可降低并发数或后台优先级，整机其他应用仍可正常使用。界面显示的占用、用量和费用来自实际测量，估算值标明为估算，示例数据不计入合计。内存和磁盘占用可见、可设上限，逼近上限时预警；传输带宽的限制见 TRANSFER-03。\
  常见问题：后台索引占满全部处理器，应用自身流畅，视频会议持续卡顿。
- [ ] **TASK-14 使用中的子系统故障隔离** · 基线 — 预览、渲染、转换或连接等可独立恢复的子系统失败时，其他文档和未保存内容保持可用，用户能定位到受影响的部分并重试。单个扩展崩溃、无响应或占用资源异常时，主程序、其他扩展和未保存内容保持可用，界面指出出问题的扩展，并可以停用或重新启动它。\
  常见问题：一份附件导致预览进程崩溃，整个应用退出，另一份文档的编辑一并丢失。
- [ ] **TASK-15 长任务的输入版本一致性** · 基线 — 导出、转换、上传或批处理使用一个明确的输入版本；任务进行期间继续编辑或替换源内容，不会产生前半部分旧、后半部分新的混合结果。\
  常见问题：导出进行到一半时用户修改了文档，导出的 PDF 前几页和后几页来自不同版本。
- [ ] **TASK-16 任务结束后的收尾动作** · QoL — 下载、转换、播放列表等长任务结束后，可预先选择收尾动作：退出、关机、睡眠、运行外部程序或删除源对象；关机和删除类动作只作用于本次任务，不作为持久设置保留；执行前有可取消的倒计时；删除前的验证与失败时的保护见 DATA-06。\
  常见问题："播放完删除文件"被保存为持久设置，第二天打开另一个视频，看完就被删除。
- [ ] **TASK-17 计划任务与错过的执行** · QoL — 已安排但尚未执行的操作（定时发送、计划任务）可查看、修改和取消。计划任务因关机、睡眠或执行条件不满足而错过时，状态中标明错过，并按说明的策略跳过、尽快补跑或等待确认。错过多个周期时，说明合并为一次还是逐次执行。补跑前，原计划附带的关机、注销等收尾动作先征得确认。任务列表显示上次实际执行时间和下次计划时间。\
  常见问题：用户以为昨夜的备份已经运行，实际计算机整夜睡眠，任务被跳过且没有任何标记。

## NETWORK · 网络、离线与同步 `联网`

- [ ] **NETWORK-01 连接状态** · 基线 — 区分离线、连接中、服务不可达和认证失败；提示与实际状态一致；需要门户登录的网络、名称解析失败和目标服务故障可区分。
- [ ] **NETWORK-02 超时与重连** · 基线 — 请求设有超时。自动重试或重连期间，界面显示正在等待或再次尝试，并提供停止的方式；持续重连还是尝试若干次后停止，可在状态或设置中看出。用户停止的任务不因先前排定的重试再次执行。重试不重复提交，副作用保护见 TASK-05。
- [ ] **NETWORK-03 离线边界** · 基线 — 离线或登录过期时，可用的数据和操作一目了然；已下载的缓存和本地历史可查看、可搜索；未提交的本地工作受到保护；本地数据不被全屏登录框阻挡。界面标明哪些内容来自缓存、可能不完整，以及离线期间哪些授权会过期。来自缓存或上次成功获取的数据标明获取时间；刷新失败时保留已有数据，同时标明未能更新，不显示为最新。行情、天气、位置等时效敏感的数据，标出的是数据本身的时间。可选账号的登录失效时，不需要账号的功能（检查公开更新、下载公开资源）照常进行，同时提示重新登录。
- [ ] **NETWORK-04 待同步队列可见** · 基线 — 离线修改和待上传内容显示状态；退出前可看到尚未上传的内容。同步类产品提供活动记录，可以查到何时与哪台设备同步了哪些对象，以及哪些对象被跳过、原因是什么。因服务端存储配额、单个文件大小或文件数量上限而停止上传时，状态显示为受限而不是已同步，并说明原因、受影响的对象和解除办法；受限期间的本地修改保留在本机。限制解除后，此前被跳过的内容自动重新上传，无需重置同步。同步的确认、被拒绝的修改和删除见 NETWORK-10。
- [ ] **NETWORK-05 代理与企业网络** · QoL — 跟随系统代理，可手动配置 HTTP / SOCKS5；自签名证书和受限网络有明确提示。登录、核心 API、图片、下载、插件市场和更新器可能使用不同的网络栈，需逐一验证代理行为。代理设置可测试连接、可设不走代理的地址；多网卡环境下可指定出口网卡和 IP 协议族；用户限定了代理或网卡时，所选通路不可用则停止连接并说明，不改走直连。
- [ ] **NETWORK-06 流量控制** · QoL — 大文件传输、后台更新和按流量计费的网络下，用户可控制触发条件。
- [ ] **NETWORK-07 登录回调** · 基线 — 使用第三方账号或单点登录时，登录页在系统浏览器或系统提供的认证界面中打开，网址可以核验；应用窗口内不出现索取其他服务密码的网页表单。通过浏览器登录后，返回原窗口和原任务，保留此前的输入；只接受与当前授权请求匹配的回调；处理取消、超时、回调失败、重复回调、多实例和账号选择等情况。实现要点见附录 A。
- [ ] **NETWORK-08 传输加密与服务身份验证** · 基线 — 账号、私密内容和受保护服务通过验证服务身份的加密连接传输；证书验证失败时停止敏感操作并说明原因，不自动关闭验证继续发送凭据。\
  常见问题：公司代理环境中连接失败，应用自动关闭证书验证，此后账号凭据也通过该连接发送。
- [ ] **NETWORK-09 IPv6 网络可用性** · 基线 — 在只有 IPv6 的网络中，登录、核心请求和下载正常工作，没有硬编码的 IPv4 地址依赖。\
  常见问题：登录正常，应用内下载却因硬编码的 IPv4 地址永久失败。
- [ ] **NETWORK-10 同步以服务端确认为准** · 基线 — 修改在服务端确认接受后才显示为已同步。被服务端拒绝的修改（校验失败、无权限、冲突）保留在本机并标明原因，可以修改后重新提交或放弃，不被随后的刷新覆盖。在一台设备上删除的对象，不因另一台设备离线期间保留的旧副本或一次全量刷新而重新出现。修改的先后以服务端记录的版本判断，不依赖各设备的时钟。冲突时保留两个版本见 DATA-07。\
  常见问题：笔记在台式机上删除后，离线一周的笔记本联网时又把它上传回来。
- [ ] **NETWORK-11 离线保留** · QoL — 只在本机保留部分在线资料的产品，用户可以把选定的内容设为离线保留。准备过程显示进度，完成后标明实际包含的范围（子页面、附件、数据库的行数）和未能准备的部分。自动清理缓存或回收空间时不移除这些内容。存储空间不足、授权撤销或远端删除导致无法继续保留时，标明受影响的内容和原因，不再显示为可离线。移除本地副本与删除远端内容的区分见 DATA-10。\
  常见问题：出发前笔记显示已下载，断网后才发现附件已被缓存清理回收，只剩正文。

## SYSTEM · 系统集成

- [ ] **SYSTEM-01 登录时启动** `后台` · 基线 — 可开关；设置中显示的状态与系统中实际注册的状态一致；卸载时移除。使用最终发行包注销并重新登录一次，确认应用按设置启动或不启动。提供启动时最小化或隐藏的选项；延迟启动，不拖慢登录。系统要求用户批准登录项时，显示"待批准"，并提供打开相应系统设置的入口。\
  常见问题：设置中已关闭，开机后应用仍自动启动。
- [ ] **SYSTEM-02 托盘或菜单栏入口** `后台` · 基线 — 可查看状态、打开窗口和明确退出；Linux 目标桌面没有托盘时提供替代入口，进程始终可找到、可退出。托盘和菜单栏图标在浅色和深色栏上均可辨认（macOS 使用模板图像），16 像素下清晰。不在 Dock 或任务栏显示图标的应用打开设置、更新、关于等窗口时，窗口显示在前台并接收键盘输入，打开期间可以用 ⌘Tab 或 Alt + Tab 切换回来。再次点击托盘或菜单栏图标，关闭它打开的面板。入口失效时的处理见 SYSTEM-11。
- [ ] **SYSTEM-03 系统通知与注意力** · 基线 — 使用系统通知中心；遵循勿扰模式和用户的通知偏好；点击通知后定位到对应对象。同类事件合并。应用提示音遵循系统音量和静音设置，并可在应用内关闭。引发通知的问题已解决或已在别处处理后，撤回已显示和排队的通知。需要用户处理的持续问题定期重提，不反复弹出。系统通知显示本应用的名称和图标。通知可以按事件类型分别设置是否弹出、是否发声。设置中可以发送一条测试通知；系统层面关闭了本应用的通知时，在设置旁说明，并提供打开系统设置的入口。应用内提示见 SYSTEM-16。
- [ ] **SYSTEM-04 全局快捷键** `后台` `浮窗` · 基线 — 可配置、可关闭；检查系统返回的注册结果，分别显示"设置已启用"和"实际已生效"；能确定原因时才提示冲突，否则提供更换按键、重试或替代入口。前台窗口以管理员身份运行或启用了安全输入时热键失效，能检测到时说明原因和替代做法；已生效的热键在运行中失效时状态随之更新，应用自动重新注册，并提供手动重新加载的入口。双击修饰键类热键的间隔可调，期间按下其他键时不触发。应用内快捷键可以逐条设为全局生效。按前台情境暂停见 SYSTEM-15。
- [ ] **SYSTEM-05 文件关联与打开方式** · 基线 — 用户可选择关联的文件类型；从外部打开文件时的窗口路由见 WINDOW-05；应用出现在系统的"打开方式"列表中。关联到本应用的每种文件类型有自己的文档图标和类型名称，在文件管理器的各种图标尺寸和深浅色主题下清晰可辨，与应用图标及其他类型区分得开，不显示为空白或通用图标。关联被其他程序接管或指向已移动、已卸载的副本时，可从应用内重新关联，或跳转到系统的默认应用设置；向外打开链接、邮件和文件时遵循用户设定的默认程序。
- [ ] **SYSTEM-06 协议与深度链接** · 基线 — 支持的链接可定位到正确内容；校验参数，安全处理未知或恶意参数；外部参数不会被解释为额外命令、启动选项或文件操作。
- [ ] **SYSTEM-07 任务栏与 Dock** · QoL — 图标和名称易于辨认；长任务在任务栏或 Dock 上显示进度；未读或待处理项以徽标显示，计数与清除见 SYSTEM-14；跳转列表或 Dock 菜单提供常用入口（Linux 视桌面环境而定）。图标在任务栏、Alt + Tab、开始菜单和文件关联等处的各种尺寸下清晰。应用可以在开始菜单和启动器中按名称和通用名称搜到（例如用"Markdown 编辑器"找到具体产品）。运行窗口与固定图标的归组见 SYSTEM-17。
- [ ] **SYSTEM-08 阻止睡眠** · 基线 — 仅在长时间渲染、大文件传输、播放、放映、同步或批量任务期间阻止系统空闲睡眠；暂停、失败、完成或退出时释放。该请求仅针对空闲睡眠，合盖、手动睡眠和关机照常进行。视频播放和放映期间同时阻止显示器关闭；音频播放、下载和同步只阻止系统睡眠，不让屏幕常亮。持久修改系统设置的情况见 SYSTEM-13。
- [ ] **SYSTEM-09 共享、打印与系统服务** · QoL — 适用时接入系统分享、打印和快速预览；服务不可用或用户取消时正确处理。能接收文字、链接或文件的产品出现在系统分享面板的目标中，接收后定位到新建或更新的对象。打印前可确认目标、纸张和范围；区分已提交到系统队列与实际完成；失败后重试不重复提交。深色主题下打印内容时，使用适合纸张的浅色配色。
- [ ] **SYSTEM-10 命令行入口** · QoL — 可从终端以 `app 文件` 或 `app .` 打开，`--help` 和 `--version` 可用；按产品的窗口模型转到合适的实例；需要新实例、等待完成或无界面执行时，参数和输出行为有文档说明。执行类自动化见 AUTOMATE。
- [ ] **SYSTEM-11 系统能力不可用时的替代入口** `后台` `浮窗` · 基线 — 热键注册失败、托盘不显示、通知被关闭或桌面门户不可用时，仍可通过应用图标、菜单或命令行重新打开窗口和退出应用。能检测到的失败优先给出反馈。用户的设置会使托盘图标、热键等入口全部失效时，保存前提示，并说明再次打开设置的方法。托盘、全局热键、通知等系统集成初始化失败或所需的系统库缺失时，应用照常启动，只停用该项并说明原因。
- [ ] **SYSTEM-12 关机、注销与系统重启** · 基线 — 收到系统关机或注销通知后快速保存状态并退出；确需阻止关机时显示原因；系统更新重启后可注册自动重启并恢复会话。实现要点见附录 A。\
  常见问题：关机时应用阻止了流程却不说明原因，用户只看到"某应用阻止关机"。
- [ ] **SYSTEM-13 对系统全局设置的修改可还原** · 基线 — 应用修改系统代理、电源设置、勿扰状态或默认音频设备等全局设置时，正常退出、崩溃或被强制结束后都能恢复原状。恢复前确认当前值仍是本应用设置的值；期间已被用户或其他程序修改时，保留现值并说明。无法自动恢复时，下次启动检测到残留并告知用户。修改系统全局设置的入口说明这项修改作用于整台计算机或所有用户，并提供恢复到修改前状态或系统默认值的操作。空闲睡眠请求见 SYSTEM-08。\
  常见问题：代理客户端被强制结束后，系统代理仍指向已关闭的本地端口，整台计算机无法访问网络。
- [ ] **SYSTEM-14 未读与待处理状态如实** · QoL — 有未读概念的产品，只在内容出现在活动且未锁定的窗口中时标为已读；重新进入时可定位到第一条未读，也可以手动标回未读。处理后，应用内的标记、任务栏或 Dock 徽标和对应的系统通知同步清除；多设备产品同步已读状态，并提供修正失步的途径。\
  常见问题：启动时自动打开上次的频道，几百条未读消息被一次性标为已读，用户无从得知错过了哪些内容。
- [ ] **SYSTEM-15 全局功能按前台情境暂停** `后台` `浮窗` · QoL — 热键、鼠标手势、剪贴板监视、文本展开等全局生效的功能，可按应用排除，可设为前台为全屏或游戏窗口时、远程桌面或虚拟机窗口在前台时自动暂停，避免主机与客机同时响应；提供整体暂停，暂停状态在托盘图标上可辨认，并保留另一唤起入口（见 SYSTEM-11）。\
  常见问题：主机和远程桌面里都装了同一款剪贴板工具，双击 Ctrl 后两边各弹出一个窗口。
- [ ] **SYSTEM-16 应用内提示与提示记录** · 基线 — 应用在前台时使用应用内反馈。高频的成功操作使用轻量的局部反馈，不每次弹出 toast；重要的失败在 toast 消失后仍可找到状态和处理入口。应用内提示有集中的记录入口，可以回看已消失的提示，未读的警告和错误有计数；提示附带的操作在仍有效时可从记录中执行，失效后标明。系统通知见 SYSTEM-03。\
  常见问题：同步失败只弹出一个几秒后消失的 toast，之后在界面上找不到失败原因和重试入口。
- [ ] **SYSTEM-17 启动入口与运行窗口为同一项** · 基线 — 从开始菜单、启动器或固定在任务栏、Dock 上的图标启动后，运行中的窗口与该图标归为同一项，显示应用自己的图标和名称，不另出现一个通用图标。再次点击该图标时，按 WINDOW-05 的规则转到已有窗口。程序更新、重新安装或移动安装位置后，已固定的图标和快捷方式继续指向当前版本。实现要点见附录 A。\
  常见问题：每次更新后，任务栏上固定的图标变成空白文档图标，点击后系统提示删除该快捷方式。
- [ ] **SYSTEM-18 自有格式在文件管理器和系统搜索中可识别** · QoL — 有自有文件格式的产品，其文件在文件管理器中显示反映内容的缩略图，在预览窗格或快速查看中可以浏览内容，作者、尺寸、时长等属性显示在详细信息中；系统搜索可以按文件内容和这些属性找到它们。生成缩略图、预览和索引时不执行文件中的主动内容（见 TRUST-01），不修改文件，不意外触发云盘占位文件的下载。遇到损坏或过大的文件时退回文档图标，文件管理器不因此失去响应或崩溃。实现要点见附录 A。\
  常见问题：一个损坏的工程文件使资源管理器每次打开所在文件夹都崩溃重启。
- [ ] **SYSTEM-19 文件管理器中的右键菜单与新建项** · QoL — 应用加入文件管理器右键菜单的命令只出现在适用的文件类型和位置上；在 Windows 11 中显示在第一级菜单，不需要先打开"显示更多选项"。加入的命令不使右键菜单明显变慢。右键菜单项和"新建"菜单中的文档模板可以在应用设置中逐项关闭，关闭后立即生效，更新后不恢复（见 FAIR-02）。实现要点见附录 A。\
  常见问题：安装后每个文件和文件夹的右键菜单里都多出三个命令，设置中找不到关闭的地方。

## INSTALL · 安装、更新与卸载 `分发`

- [ ] **INSTALL-01 安装范围与首次启动** · 基线 — 提供适合目标用户和渠道的安装范围：可按用户安装时不请求管理员权限，必须提权时说明原因；允许自选路径的安装程序接受合理路径；首次安装失败时撤回已产生的注册项和服务。首次启动时说明数据位置和所需权限。以管理员身份运行的副作用与按需提权见 INSTALL-13，签名与系统拦截见 INSTALL-12。
- [ ] **INSTALL-02 版本与更新责任** · 基线 — 可查看当前版本；更新的负责方和通知方式遵循当前分发渠道的约定。通过应用商店和包管理器分发时，通常由渠道负责更新；应用自行更新时按渠道规则声明（例如 Homebrew Cask 的 `auto_updates`）。产品改名或更换发行身份（安装标识、签名、包名）后，升级仍识别原有安装，并沿用或迁移已有的设置、数据和凭据访问。无法延续的系统授权可以在应用内重新授予。当前系统不再获得新版本时，应用说明这一点并显示最后兼容的版本，不显示为"已是最新"。
- [ ] **INSTALL-03 更新偏好** · 基线 — 在渠道和管理策略允许的范围内，更新行为可理解、可控制：应用自行管理更新时，提供自动、提醒、手动等选项；受管环境下显示负责方；检查和下载在后台进行；用户编辑或执行任务时不强制重启；支持"下次退出时完成更新"。退出时安装更新不使应用自行重新启动；静默更新后的重启保持原来的托盘、隐藏或最小化状态。按计算机安装、可被多个用户同时使用的产品，更新不关闭其他用户会话中正在运行的实例：等这些实例退出后再替换，或先通知各会话的用户并允许保存。
- [ ] **INSTALL-04 更新失败后可用** · 基线 — 检查、下载、安装和失败状态可见；更新失败后旧版本照常可用。安装或更新前检查目标版本对系统版本、处理器架构和运行环境的要求，不满足时不替换当前版本，并说明原因。
- [ ] **INSTALL-05 程序回滚与数据回退** · 基线 — 新版本写入过的数据用旧版本打开时，明确拒绝、只读打开或进入恢复流程，数据不受损坏；无法安全降级时说明原因，并提供保留副本的方式。升级时数据迁移失败的回滚见 DATA-10。
- [ ] **INSTALL-06 卸载范围** · 基线 — 移除启动项、文件关联及文档图标、缩略图与预览组件、搜索索引组件、服务、全局快捷键和右键菜单项，以及随附的辅助服务、下载的资源和私有字体；用户可选择保留或删除用户数据，并了解具体范围；用户创建的文件、共享组件和同一计算机上的其他版本不受影响；重新安装后数据不丢失。系统"已安装的应用"列表中的名称、发布者、版本、图标和占用空间与实际一致，更新后随之更新；从该列表卸载能完成，卸载后条目消失。
- [ ] **INSTALL-07 更新包真实性** · 基线 — 应用自行更新时，用内置公钥验证更新包签名，签名不符则拒绝安装；版本清单同样签名，版本号与更新包摘要绑定；防回退检查依据签名过的版本信息，服务器或中间人因此无法诱导用户安装有漏洞的旧版本。实现要点见附录 A。\
  常见问题：只依赖 HTTPS 保护更新，被篡改的清单将用户降级到已知漏洞版本。
- [ ] **INSTALL-08 更新的下载与安装** · 基线 — 下载前检查磁盘空间，中断后可续传，安装前校验哈希；能替换正在运行的程序文件，或在退出后、下次启动时完成替换；安装位置不可由当前用户写入时有提权或替代路径，不静默失败；通过应用商店或包管理器安装的副本是否自行更新，按渠道规则决定（见 INSTALL-02）。更新完成后清理旧版本的程序文件和下载的安装包，安装目录的占用不随更新次数增长。\
  常见问题：更新器试图覆盖正在运行的程序文件，报"文件被占用"后留下半套新文件。
- [ ] **INSTALL-09 全新系统上的运行时依赖** · 基线 — 在声明支持的干净系统上，使用最终发行包安装后能完成首次核心任务；依赖的运行时（WebView2、VC++ 运行库、.NET、Java、Python、GTK）由安装程序检查并安装，或在缺失时给出名称、用途和获取路径。\
  常见问题：开发机装有 Python，发行包因此漏带运行时；用户双击后没有任何窗口出现。
- [ ] **INSTALL-10 从只读或受保护位置运行** · 基线 — 从 DMG、网络共享、只读挂载或非管理员的 Program Files 启动时正常运行，运行状态写入用户可写的位置；需要移动或安装时说明原因和操作（macOS 上提示拖到 Applications）。\
  常见问题：直接从 DMG 启动，应用试图在程序旁创建数据库，首次启动永久停在加载画面。
- [ ] **INSTALL-11 处理器架构** · 基线 — 在 Apple Silicon、Windows on ARM 和 Linux aarch64 上原生运行，或明确声明通过模拟运行；安装程序和更新器选择与系统匹配的架构；随附的辅助程序同样原生运行，或明确声明通过模拟运行。\
  常见问题：主程序是 arm64，随附的 x64 FFmpeg 在 Windows on ARM 上通过模拟运行，转码速度只有原生的几分之一。
- [ ] **INSTALL-12 签名、来源核验与系统拦截** · 基线 — 下载来源和发布者可核验；Windows 和 macOS 上所有可执行文件（包括辅助程序、更新器和卸载器）均已签名，Linux 上软件包或软件源已签名；SmartScreen、Gatekeeper 等系统拦截有说明和正确的处理方式，已签名的新版本在积累信誉前仍可能触发 SmartScreen 警告；组件被安全软件隔离时说明受影响的组件和修复路径。\
  常见问题：主程序通过了 SmartScreen，首次调用未签名的转码辅助程序时弹出"未知发布者"警告。
- [ ] **INSTALL-13 以普通权限运行，按需提权** · 基线 — 主程序默认以普通权限运行，只有需要管理员权限的操作才单独提权，入口上标出提权标记（Windows 为盾牌图标），操作完成后回到普通权限；需要持续系统权限的部分放在服务或辅助进程中。以管理员身份运行时提示其副作用：Windows 下从未提权的程序（如资源管理器）拖入会被阻止；以另一个管理员账户运行时，配置写入该账户的目录；标准权限下映射的网络驱动器在提权进程中不可见；从本应用启动的程序同样以管理员身份运行。\
  常见问题：整个程序以管理员身份运行，用户无法把资源管理器中的文件拖进窗口。

## PRIVACY · 权限、账号与隐私

- [ ] **PRIVACY-01 按任务申请权限** · 基线 — 需要时才申请权限，说明访问的内容和用途；用户拒绝后其余功能仍可使用。系统权限请求中由应用提供的用途说明使用用户的界面语言，写明具体用途。
- [ ] **PRIVACY-02 权限撤销后的处理** · 基线 — macOS 隐私设置、Linux 沙箱门户或目录授权被撤销后，给出提示并提供重新授权的方式。需要多项系统权限的产品，在一处列出各项权限的用途、当前状态和授权入口。系统设置中显示已授权、应用实际未获得权限时（常见于系统或应用升级之后），应用按实际状态显示为未生效，并给出与当前系统版本一致的恢复步骤。设备或服务无法使用时，区分系统隐私设置拒绝、授权尚待确认、设备被其他程序占用和设备不存在，分别说明并给出对应入口，不统一显示为"未找到设备"。用户在系统设置中授予权限后，应用自动识别并启用相关功能；平台要求重启才能生效时，说明这一点并提供重新启动的按钮。
- [ ] **PRIVACY-03 凭据存储** · 基线 — 密钥和登录状态存放在系统钥匙串或凭据管理器中（Windows Credential Manager、macOS Keychain、Linux Secret Service），不出现在日志、导出文件、截图和界面明文中。显示、复制、记录或在浏览器中打开含凭据的地址（仓库远程地址、代理地址、连接串）时，去掉其中的凭据部分。钥匙串被锁定、不存在或迁移后解密失败时，提供"仅本次会话使用"或重新登录，不静默改为写入普通配置文件。凭据不出现在辅助程序的命令行参数和错误回显中；保存的凭据只用于授权的服务，跟随重定向或切换镜像时不转发。Linux 上的实际保护程度取决于可用的 secret store 后端。
- [ ] **PRIVACY-04 遥测透明、可关闭** · 基线 — 说明发送的内容和目的；默认值合理；当前状态可查看，可随时关闭。不携带用户内容的自发连接（更新检查、扩展列表、在线资源）同样列出用途和关闭方式，以本地工作为主的产品提供联网总开关；由服务端控制的功能实验与遥测分开说明，可查看当前生效的实验并退出。崩溃报告的内容与脱敏见 HELP-05。
- [ ] **PRIVACY-05 退出与切换账号或工作区** `联网` · 基线 — 草稿、待同步内容、下载和本地缓存的归属明确；切换前可看到未完成的工作。退出或切换账号后，旧账号已安排的提醒被取消，已显示的通知被撤回，点击残留的旧通知不会打开旧账号的内容。旧账号延迟响应的处理见 TASK-11。
- [ ] **PRIVACY-06 账号数据的查看、导出与删除** `联网` · 基线 — 提供入口，并说明影响范围。
- [ ] **PRIVACY-07 敏感内容的显示与复制** · QoL — 通知预览、历史记录和分享界面中的敏感内容可隐藏。复制密码或令牌后的定时清除只清除应用自己写入的内容，保留用户之后复制的内容；可按需将其排除在系统剪贴板历史和云同步之外，并说明保护范围。有明确隐私需求的窗口可按平台能力排除在屏幕共享和窗口预览之外，并说明生效范围。搜索、运行等历史记录可分类清除，可设为退出时自动清除；停止记录不删除已有记录，清除有独立入口。应用锁见 PRIVACY-13。
- [ ] **PRIVACY-08 云端处理透明** `联网` · 基线 — 用户知道哪些内容会离开设备、发送到何处，并可选择或停止；处理方和处理区域可识别；第三方组件的外传同样包含在说明和控制范围内。
- [ ] **PRIVACY-09 本机服务与进程通信的访问边界** · 基线 — 应用内部的本机服务和进程间通信只接受预期调用方的连接：网页、局域网设备和同一计算机的其他用户无法借此读取数据或执行操作；启动时不触发防火墙提示。实现要点见附录 A。用户主动开启、供其他程序或设备调用的服务（本机 API、局域网共享），在开启处显示当前可访问的范围以及是否要求身份验证；扩大访问范围的选项（监听所有网卡、允许任意网页跨域访问）在开启前说明后果。\
  常见问题：连接界面与下载引擎的服务监听所有网卡且无认证，局域网内其他设备可以添加任务。
- [ ] **PRIVACY-10 剪贴板与按键的读取时机与用途** · 基线 — 只在用户触发粘贴或明确启用相关功能时读取剪贴板；持续监测剪贴板的功能有可见状态和关闭入口，读取的内容只用于声明的用途。持续记录剪贴板的功能遵循来源应用设置的排除标记（例如密码管理器复制的内容），并且可以按应用排除。显示、记录或匹配全局按键的功能（按键显示、宏录制、文本展开），在密码输入期间不显示、不记录、不匹配按键，暂停状态可以辨认。\
  常见问题：后台工具为识别链接持续读取剪贴板，并将刚复制的密码作为诊断事件上传。
- [ ] **PRIVACY-11 导出与分享中的隐藏信息** · QoL — 导出、发布或分享前，用户可识别并按需移除随结果携带的位置、作者、修订记录、批注和隐藏内容等元数据。提供涂黑、删减或"移除敏感信息"的产品，处理后的分享副本中，被移除的文字和图像无法通过复制、搜索、移除覆盖层或提取嵌入内容重新取得；尚未应用的标记与已处理的结果可区分。\
  常见问题：用户删除了文档中的姓名，导出的文件仍保留作者信息和带姓名的批注。
- [ ] **PRIVACY-12 条款与隐私政策持续可访问** · 基线 — 用户在接受条款或提供数据前能阅读完整文本，之后可从应用内重新访问，并能识别适用的版本。\
  常见问题：隐私政策只在首次启动时弹出一次，关闭后再无入口。
- [ ] **PRIVACY-13 应用锁的保护范围** · 基线 — 提供应用锁的产品，锁定时主窗口、副窗口、快捷面板、窗口预览和通知预览一并受保护；空闲时间按系统级输入计算；系统锁屏或睡眠时应用一并锁定，解锁后回到原工作位置。应用锁可以使用系统身份验证（Windows Hello、Touch ID）解锁。忘记应用锁密码时的恢复途径及其代价（例如是否清除本地数据）事先说明。连续输错被临时锁定时，显示剩余的等待时间。\
  常见问题：主窗口已锁定，但快捷面板仍显示最近的对话，任务栏预览也仍是锁定前的画面。
- [ ] **PRIVACY-14 分享范围与收回** `联网` · 基线 — 能生成分享链接、邀请他人或发布到网页的产品，分享时和分享后都可查看当前的访问范围（指定的人、组织内、任何获得链接的人）和权限（查看、编辑、下载）。同一内容有多条访问途径（直接邀请、分享链接、发布到网页）时，在一处列出，并可逐条停止。分享可设期限，到期后链接失效。停止分享、链接到期或禁止下载时，说明对方已下载或已复制的副本不受影响。\
  常见问题：用户取消了"发布到网页"，以为文档已转为私有，但"获得链接的任何人可查看"仍然开启，此前转发的链接照样能打开。
- [ ] **PRIVACY-15 发给他人的活动状态** `联网` · QoL — 向其他用户显示在线状态、已读、正在输入或浏览记录的产品，这些状态可以在设置中分别关闭。关闭后对自己的影响（例如同时看不到他人的已读状态）和不受开关控制的例外（例如群聊、管理员策略），写在开关旁。在线状态自动变为离开时，判断依据（空闲时长、锁屏、最小化）可以查到；手动设定的状态保持到用户更改或设定的时长结束。\
  常见问题：用户关闭了已读回执，以为对方不再知道自己看过消息，群聊中的已读状态却照常发出。

## HELP · 帮助、反馈与诊断

- [ ] **HELP-01 首次引导** · QoL — 用户能完成第一个核心任务；引导可跳过、可重新查看。
- [ ] **HELP-02 空状态说明下一步** · QoL — 列表为空、无结果或未配置时，说明用户接下来可以做什么。区分"未找到"与"未搜索完"：索引中、同步中、权限不足、范围过窄和确实不存在分别给出不同提示。
- [ ] **HELP-03 错误信息可操作、可复制** · 基线 — 说明失败的对象、原因和可采取的措施；提供可直接执行的恢复操作（重试、另存到其他位置、检查代理、打开相关的应用设置或系统设置页面、复制详情）；技术详情可展开、可复制。打开文件失败时区分文件损坏、缺少组件和当前分发版本不支持。保存被受控文件夹访问、安全软件或云盘客户端拒绝时，错误信息指出这一可能，并说明加入例外的方法。按钮、菜单项或设置暂不可用时，可以查到原因和启用条件；启用条件是某项设置时，可直接打开该设置。错误详情包含不随界面语言变化的错误代码或标识，便于搜索和报告。\
  常见问题：错误对话框只显示"发生错误（代码 -1）"。
- [ ] **HELP-04 帮助入口与版本匹配** · QoL — 帮助、FAQ 和文档入口对应当前版本。界面、设置、错误信息和帮助中，同一对象和命令使用同一名称；界面中的名称改变后，帮助同步更新。
- [ ] **HELP-05 诊断日志与诊断包** · QoL — 可打开日志目录；可导出诊断包，说明其中包含的内容，发送前可预览或选择范围。脱敏范围包括令牌、路径、搜索词、配置、个人词典、截图和崩溃转储。本地日志和崩溃转储同样按敏感程度控制内容和保留时间；日志轮转并有大小上限。诊断包包含随附组件的名称和版本。发行版在每个支持的平台上都能取得崩溃信息，包括启动阶段和原生代码中的崩溃。窗口从未出现时，启动错误可通过带控制台的启动入口、调试启动脚本或启动日志取得，文档说明位置。登录、解锁或主要功能失败时，仍可取得不依赖该功能的基础诊断，并说明缺少哪些信息。临时提高日志级别或采集网络、性能数据时，采集范围、当前状态和停止入口可见，结束后可恢复原来的日志设置。
- [ ] **HELP-06 反馈入口** · QoL — 可附带环境信息；发送前用户可审阅内容。提交前说明问题描述和附件的可见范围（公开、持链接可见或仅支持人员可见）；敏感诊断材料可以通过与公开描述分开的私密途径提交。
- [ ] **HELP-07 安全模式与自助恢复** · 基线 — 插件、主题、配置或 GPU 加速导致应用无法正常运行时，可以最小配置启动（通过命令行参数，或在连续启动失败后自动询问），不改动用户数据。按三个步骤处理：先临时隔离测试，再针对性禁用，最后才大范围重置；退出临时模式后恢复原环境。插件较多的产品提供批量禁用或二分排查，排查结束后恢复原状态。启动迟迟不能完成时，同样提供以安全模式重新启动的入口。派生数据的重建见 DATA-15，第三方注入模块的排查见 HELP-10。
- [ ] **HELP-08 更新内容说明** · QoL — 升级后首次启动时，通过一处轻量入口说明变更内容，尤其是默认行为或快捷键的变化；可关闭，可在帮助菜单中重新查看，不在每次启动时弹出。界面或默认行为大幅改变时，过渡期内保留回到旧版的选项，并在移除前告知。\
  常见问题：更新更改了常用快捷键，用户误以为软件出现故障。
- [ ] **HELP-09 示例内容与模板** · QoL — 空工作区提供示例文档、示例项目或模板，用户无需从空白开始即可了解软件功能；示例可一键删除，与用户数据分开存放。
- [ ] **HELP-10 第三方注入模块与干扰软件** · QoL — 注入进程或挂钩系统 API 的第三方软件（屏幕覆盖层、取词词典、沙箱、安全软件、外壳扩展、过时的数位板驱动）导致白屏、崩溃、冻结或启动卡住时，帮助文档维护已知冲突清单和处理方式；诊断工具列出已载入本进程的第三方模块及其厂商，标出常见冲突来源，并给出加入例外的指引，不只建议关闭安全软件；诊断包（HELP-05）包含这份列表。\
  常见问题：另一款软件的取词功能让应用随机冻结，故障排除页唯一的建议是"暂时禁用杀毒软件"，企业电脑上用户没有这个权限。

## FIND · 搜索与筛选

适用：内容、对象、命令或记录较多的产品。相关条目：命令面板 INPUT-05，设置搜索 SETTINGS-02，"未找到"与"未搜索完" HELP-02，跨视图恢复 WINDOW-06。

- [ ] **FIND-01 范围与排除条件可见** · 基线 — 搜索或筛选时显示当前范围（当前文件、当前库、整个项目）和生效的排除条件；无结果时可检查或扩大范围。打开查找时，以当前选中的文本作为初始查询。选区跨多行时，可以改为在选区内查找。依赖系统搜索索引的产品，说明系统排除或尚未索引的位置不会出现在结果中，并提供打开系统索引设置的入口。\
  常见问题：上次会话留下的"仅当前目录"筛选未显示，用户搜索不到确实存在的文件。
- [ ] **FIND-02 命中可辨认、结果可遍历** · QoL — 结果显示足以区分对象的路径、上下文或命中位置；可用键盘连续遍历、打开、返回并定位到命中处；结果刷新不改变当前选中项。打开结果后可在应用内部的目录或树中定位该对象。\
  常见问题：十个结果都名为"笔记"，没有路径和摘要；按"下一项"后又回到第一项。
- [ ] **FIND-03 匹配方式可见** · QoL — 按产品需要支持模糊、精确、区分大小写和正则等匹配方式，当前模式和筛选条件可见；不支持的语法有说明，无法解析的输入显示为语法错误。可排序的列表和表格标出当前排序的列和方向。多语言书写变体见 LOCALE-05。\
  常见问题：上次启用的正则模式仍在生效，搜索带括号的文件名时匹配失败，界面上看不出原因。
- [ ] **FIND-04 重复检索** · QoL — 需要反复查询的产品保留最近的查询，可固定常用条件，可复制结果；恢复的查询条件可辨认、可快速清除；敏感查询的保留与清除符合产品的隐私预期。历史记录的分类清除见 PRIVACY-07。\
  常见问题：在共用计算机上，上一位用户的敏感搜索记录被自动恢复。
- [ ] **FIND-05 个人标记与稍后处理** · QoL — 需要反复回到特定对象或位置的产品，允许用户给对象、段落或行加标记，并在集中入口中直接回到该处；移除标记不删除内容。\
  常见问题：已读但尚未处理的消息混在其他已读消息中，用户只能凭记忆查找。

## TRUST · 外来内容

适用：会打开来源不明的文件、工程、邮件或网页片段的产品。本节说明打开内容时授予了哪些权限、可以消耗多少资源，以及签名状态如何呈现。相关条目：应用自身的权限与数据 PRIVACY，传入的深度链接 SYSTEM-06，安装包来源与系统拦截 INSTALL-12。

- [ ] **TRUST-01 陌生内容先以受限模式查看** · 基线 — 打开含主动行为的文档或工程时，先在受限模式下查看，并告知用户哪些能力已暂停；生成缩略图或预览时不执行其中的任务；无法安全预览时说明限制。\
  常见问题：用户打开下载的工程以查看 README，工程配置中的命令已被执行。
- [ ] **TRUST-02 放行范围明确** · 基线 — 宏、脚本或工程任务需要额外信任时，说明放行范围是本次、本文件、本目录还是该发布者；拒绝后仍可进行安全范围内的阅读；放行记录可查看。"允许编辑"与"允许执行"分开授权。\
  常见问题：对一个文档点击一次"允许"后，同目录下新增的脚本全部自动运行，界面没有说明。
- [ ] **TRUST-03 外来内容的网络请求** `联网` · 基线 — 邮件、文档和预览中的远程图片、样式及其他外部资源遵循产品声明的隐私设置；被阻止时显示缺少的内容，放行范围可辨认；离线时显示可用部分。\
  常见问题：用户关闭了遥测，以为预览不会联网，邮件中的追踪图片仍被加载。
- [ ] **TRUST-04 链接目标可核验** · 基线 — 外来内容中的链接可查看或复制真实目标；显示文字与目标不一致、需要调用外部程序或使用高风险协议时，按风险程度给出提示；目标异常或用户取消时停留在原内容。普通链接不额外弹出确认。域名混用不同字母表、可能仿冒其他域名的链接，显示其编码形式或给出提示。\
  常见问题：预览中显示的是官方登录网址，点击后打开的是另一个域名，用户无法预先查看链接目标。
- [ ] **TRUST-05 归档导入的目录边界** · 基线 — 导入主题、插件、备份、项目包等归档时，内容只写入用户选定的目录；归档中的 `../` 路径和符号链接不能越界写入或替换其他文件。实现要点见附录 A。\
  常见问题：导入主题包时，其中的 `../` 路径覆盖了应用配置和用户的启动脚本。
- [ ] **TRUST-06 下载内容的来源标记交接** · QoL — 应用保存的互联网内容带有平台的来源标记（Windows 的 Mark of the Web、macOS 的 quarantine 属性），用其他程序打开时仍经过系统的信任检查。从带有来源标记的归档中解压出的文件，同样带有标记。\
  常见问题：浏览器下载的文档会进入受保护视图，同一文档经应用下载后失去来源标记，直接以完整权限打开。
- [ ] **TRUST-07 外来内容以被动方式显示** · 基线 — 显示笔记、邮件、Markdown、SVG、粘贴的富文本等外来内容时，其中的脚本和事件处理不执行。内容中的链接和嵌入不在应用窗口内载入可执行的页面。渲染出的内容读不到应用的数据和文件，也调用不了系统功能。渲染出的内容产生的按键和点击，不触发应用的快捷键、菜单命令、通知操作和确认按钮。实现要点见附录 A。\
  常见问题：笔记中的图表代码生成了带脚本的链接，预览这篇笔记时，用户计算机上执行了一条命令。
- [ ] **TRUST-08 应用界面与外来内容可区分** · 基线 — 外来内容只显示在内容区域内，不能覆盖应用的标题栏、工具栏和对话框；外来内容中的表单不在应用内提交。应用索要凭据、授予权限或确认高风险操作时，使用外来内容到达不了的独立窗口或内容区域之外的界面。显示他人消息的产品，通知、来电提示和会话标题中的发送者取自账号身份，对方可修改的显示名和会话话题不能冒充其他参与者、应用或系统；以应用或机器人身份发出的消息带有标识。\
  常见问题：服务器下发的首页不含脚本，却画出了与客户端一致的"会话已过期，请重新登录"表单，用户在其中输入了密码。
- [ ] **TRUST-09 文档签名的验证状态** · 基线 — 显示或验证文档数字签名的产品，分别标明内容在签名后是否被改动、签署者是否可信，以及因离线或缺少证书而尚未完成验证的状态，并可查看签名覆盖的内容范围。文档经编辑、修复或格式转换后，重新验证并更新状态，不沿用打开时的结论；从损坏文件中修复出的内容不显示为签名有效。签名的图形外观与经过验证的数字签名可以区分。实现要点见附录 A。\
  常见问题：损坏的签名文档经应用修复后，仍显示打开时的"签名有效"，而修复出的内容并未经过签名。
- [ ] **TRUST-10 外来文件的资源边界** · 基线 — 打开、预览或导入外来文件时，体积很小的文件不会使应用耗尽内存、磁盘或处理时间而失去响应。所需资源明显超出预期时（解压字典、解码后的图像尺寸、展开后的总体积），开始前说明并允许取消；无法预估的处理在达到上限后停止，并说明原因。停止后原文件不受影响，其他未保存的工作保持可用。资源上限的设置见 TASK-13。实现要点见附录 A。\
  常见问题：打开一个几十 KB 的归档后，应用按其中声明的字典大小申请数 GB 内存，界面卡死，未保存的编辑随之丢失。

## EXTEND · 扩展与插件

适用：支持社区插件、脚本包、可执行主题或扩展市场的产品。相关条目：应用无法启动时的临时隔离 HELP-07，组织统一管理扩展 MANAGED-05。

- [ ] **EXTEND-01 实际权限与信任边界** · 基线 — 安装前说明扩展实际可访问的范围、是否运行在隔离环境中以及信任影响。只有在技术上强制执行的限制才描述为隔离或沙箱，仅有声明的权限按完全信任说明。拒绝安装或运行扩展后，主应用照常工作。\
  常见问题：安装界面只列出"读取当前笔记"，插件实际可读写用户的其他文件并访问网络。
- [ ] **EXTEND-02 来源与依赖可辨认** `分发` · 基线 — 用户可确认扩展的标识、发布者、来源和连带安装的依赖；界面显示发布者的验证状态，便于区分同名扩展；签名或来源验证失败时有明确反馈。\
  常见问题：安装一个主题时，未经告知同时安装了多个可执行代码的扩展。
- [ ] **EXTEND-03 更新可控** `分发` · QoL — 扩展较多的产品提供更新控制、兼容性提示和恢复入口；升级失败时保留可用环境；回退旧版前说明数据和设置是否兼容。扩展更新后能力范围扩大（例如从纯主题变为包含可执行代码）时，重新征求同意。主程序更新会使已安装的扩展失效时，更新前列出受影响的扩展。\
  常见问题：主应用未变，某扩展在夜间自动更新后工程无法打开，用户无法得知是哪个扩展更新，也无法停用。
- [ ] **EXTEND-04 停用与移除的影响** · 基线 — 用户可停用或移除扩展，并知道何时停止生效、哪些设置和文档依赖会保留；停用不删除用户数据；需要重启或后续清理时有提示。\
  常见问题：卸载插件时，用户自建的词典被一并删除。

## AUTOMATE · 外部自动化

适用：涉及重复导出、转换、整理或查询工作的产品，有重复操作的截图工具和启动器同样适用。可选途径包括命令行参数、系统动作（Shortcuts、D-Bus）、脚本接口、可驱动的界面（UI Automation）和 Agent 接口（如 MCP），按产品需要选择。终端启动与窗口路由见 SYSTEM-10；完善的辅助技术语义（A11Y-03）同样有利于外部驱动。

- [ ] **AUTOMATE-01 重复任务有可组合入口** · QoL — 按任务提供命令行参数、系统动作、脚本接口或可驱动的界面，能完成查询、转换、导出等实际工作，而不仅是从终端打开窗口；不支持的操作说明边界。\
  常见问题：批处理入口每次只打开一个窗口，格式选择和确认仍需手动点击上百次。
- [ ] **AUTOMATE-02 对象与操作可准确定位** · QoL — 暴露给外部工具的对象具备稳定的标识、名称、状态和可用操作；重命名、视图变化或列表重排后，操作仍作用于原对象；无法识别时停止或重新确认。\
  常见问题：脚本固定点击"第七行的删除"，排序变化后删除了其他对象。
- [ ] **AUTOMATE-03 输入、输出与完成状态可判断** · 基线 — 可自动运行的入口明确输入范围、输出位置以及完成和失败的反馈方式（退出码、结果文件）；需要交互的步骤有文档说明，无人值守时不等待隐藏的对话框；部分成功可识别；重试的副作用保护见 TASK-05。\
  常见问题：转换失败时只打印了错误文字，调用方仍判断为成功，下一轮覆盖了原文件。
- [ ] **AUTOMATE-04 委托可开启、可停止、可查看** · 基线 — 暴露控制服务或敏感操作接口时，默认关闭或由用户开启；启用状态、调用方身份和有效授权可查看，可撤销和停止；连接失败或授权失效时不扩大权限。普通脚本操作无需逐次确认。数据离开设备的规则见 PRIVACY-08；本地服务的调用方可能将内容发送到远程模型，启用时说明这一点。\
  常见问题：用户试用一次 Agent 功能并退出客户端后，本地服务仍在运行，且找不到撤销入口。

## LICENSE · 许可、试用与到期

适用：提供试用、订阅、设备席位或版本授权的产品。本节涉及使用权变化引起的功能变化；一般导出能力见 DATA-08。

- [ ] **LICENSE-01 许可状态与可用范围** `分发` · 基线 — 用户可查看当前许可、到期后仍可使用的版本和功能，以及续订或购买入口；试用结束时显示明确的许可状态。\
  常见问题：用户购买的是永久授权的旧版本，升级后只看到"许可无效"，找不到可用的版本。
- [ ] **LICENSE-02 到期后取回已有工作** `数据` · 基线 — 许可到期或降级时，在用户仍有访问权的范围内保留查看、复制或导出的途径，并说明期限、附件和有损部分；依赖有效服务才能提供的内容事先说明；到期、认证失败和访问权撤销显示为不同状态。\
  常见问题：付费编辑功能到期后，用户自己的本地工程和导出入口也一并被锁定。
- [ ] **LICENSE-03 验证失败的处理** `分发` · 基线 — 本可离线工作的功能提供离线验证、宽限期或明确的限制；许可服务不可达时区分网络故障与许可失效，不在保存过程中关闭应用。是否提供完全离线激活由产品决定。\
  常见问题：许可服务器短暂不可达，客户端判定为盗版，未导出的工作被锁在窗口中。
- [ ] **LICENSE-04 更换设备与设备丢失** `分发` · QoL — 有设备数量限制时，可查看和释放旧设备并迁移到新设备；旧设备损坏或丢失时提供远程解绑或客服途径；迁移失败时说明原因是席位、版本还是身份问题。通过应用商店购买的权益在重装或更换设备后可恢复，商店身份与应用账号不匹配时说明原因。\
  常见问题：旧硬盘损坏，而解绑只能在旧设备上操作，新设备无法激活。

## MANAGED · 组织部署与受管环境

适用：会被公司、学校或机房批量安装、锁定配置或统一管理更新的产品。仅支持个人安装的产品可跳过本节；普通多用户计算机上的会话隔离见 WINDOW-05。代理与企业证书见 NETWORK-05。

- [ ] **MANAGED-01 无人值守部署** `分发` · 基线 — 支持批量部署的产品，安装、升级和卸载可通过有文档的非交互方式完成；管理员可获得结果、失败原因和重启要求；无人登录的会话中不显示对话框。\
  常见问题：管理系统显示命令已执行，安装程序实际在隐藏窗口中等待点击"下一步"。
- [ ] **MANAGED-02 用户与计算机范围** `分发` · 基线 — 支持多种安装范围时，说明程序、设置、数据、服务和更新分别属于哪个范围；提权失败时可退出或改选允许的范围；同一计算机上的不同用户不会误用彼此的数据，会话间的实例隔离见 WINDOW-05。支持虚拟桌面或漫游配置文件的产品，说明哪些目录保存需要随用户保留的设置和数据，哪些是注销时可丢弃的缓存，以及丢弃后的影响。缓存被清空后，设置照常保留，首次引导不再出现。实现要点见附录 A。\
  常见问题：管理员安装程序后，普通用户启动时配置被写入管理员的个人目录。
- [ ] **MANAGED-03 策略控制可见** `分发` · 基线 — 受组织策略控制的设置显示受管原因和实际生效值；用户修改与策略冲突时，明确提示修改未生效；提供求助或说明入口。组织下发的设置区分推荐的默认值（用户可以修改）和强制值（锁定），界面上两者可以辨认。\
  常见问题："自动更新"每次都能勾选，重启后又恢复原值，且没有任何受管提示。
- [ ] **MANAGED-04 隔离网络的完整路径** `分发` · 基线 — 支持隔离网络的产品，运行时、功能包、许可和必要的帮助文档都有可预先准备的离线来源；缺少组件时说明缺少的内容，不自动转为在线下载。离线帮助的覆盖范围由产品决定。\
  常见问题：完整安装包可复制到内网，但首次启动仍需下载运行时、在线激活并打开在线帮助。
- [ ] **MANAGED-05 维护责任与扩展来源** `分发` · 基线 — 组织统一管理版本或扩展分发时，用户可辨认维护者和可用的更新来源；被禁用的扩展说明原因，不绕过策略自行安装，不无限重试。\
  常见问题：主程序被锁定在固定版本，内置扩展却自动升级到不兼容的版本，普通用户无权修复。

## FAIR · 尊重用户选择

适用：包含账号、推广、付费或捆绑安装流程的产品。

- [ ] **FAIR-01 账号要求与功能相称** `联网` · QoL — 不依赖账号的本地功能可直接使用，登录要求出现在同步、协作、授权等环节；跳过登录后有明确的继续路径，"稍后登录"不反复阻断操作。\
  常见问题：用户只想查看本地文件，却必须先验证邮箱才能进入一个本可离线使用的查看器。
- [ ] **FAIR-02 安装和更新遵循用户已有选择** `分发` · 基线 — 捆绑组件、文件关联、默认程序和开机启动均明确告知并由用户选择；拒绝捆绑组件不导致安装失败；更新不恢复用户已关闭的选项。用户卸载的预装组件，重启或更新后不重新安装；用户手动安装的特定版本，默认不被自动更新覆盖。\
  常见问题：安装时取消了文件关联，下一个小版本更新后所有文件类型又被重新关联。
- [ ] **FAIR-03 推广可忽略、拒绝被记住** · QoL — 升级、试用、评分和推荐提示不遮挡当前工作，不伪装成系统警告；关闭和拒绝选项易于找到，无新变化时不重复打扰；必要的安全通知与营销偏好分开设置。\
  常见问题：用户每天关闭同一个促销弹窗，关闭按钮的文字被改为"暂时错过优惠"。
- [ ] **FAIR-04 取消订阅、退出与卸载入口** `分发` · 基线 — 用户可找到取消订阅、退出后台和卸载的入口，并了解何时停止收费、哪些服务和数据受影响；付款异常或购买渠道不同时也有可行的途径，不要求先接受无关的促销。卸载的清理范围见 INSTALL-06。\
  常见问题：付款正常时可以取消订阅，信用卡失效后取消按钮消失，只剩"补交付款"。
- [ ] **FAIR-05 价格、试用与续费条件明示** · 基线 — 确认购买或开始带后续费用的试用前，用户看得到实际扣款金额、计费周期、试用结束后的价格和自动续费条件。\
  常见问题：购买按钮突出显示折算月价，按下后一次扣除全年费用。

## COMPONENT · 随附组件与辅助进程

适用：随附 FFmpeg、aria2、Python 或 Node 运行时、字体、词典、编解码器、模型等外部组件，或启动辅助进程的产品。安装时的运行时依赖见 INSTALL-09，辅助进程的架构见 INSTALL-11。

- [ ] **COMPONENT-01 随附组件与系统副本共存** · 基线 — 应用使用自己声明支持的组件版本；系统 PATH 中出现同名工具不改变应用行为，应用也不替换或破坏系统中的同名组件。需要调用用户自己安装的命令行工具（git、python、node、包管理器）时，从 Dock、开始菜单或文件管理器启动与从终端启动，找到的是同一组工具。找不到工具时说明查找过的路径，并可以指定工具的位置。\
  常见问题：用户安装另一个软件后，应用改为调用 PATH 中不兼容的 FFmpeg，原有导出格式全部失败。
- [ ] **COMPONENT-02 按需资源的获取与移除** · QoL — 需要额外下载模型、编解码器、语言包等资源时，下载前说明用途、体积和存放位置；可查看就绪状态、重试获取和删除不再需要的资源；预先放入资源后可离线使用。\
  常见问题：点击识别按钮立即开始下载数 GB 的模型，没有说明，也没有取消和卸载入口。
- [ ] **COMPONENT-03 辅助进程的身份与生命周期** · 基线 — 主程序正常退出或被强制结束后，随主程序运行的辅助进程不残留；明确需要继续运行的组件（更新器、用户批准的后台下载、系统服务）可辨认，有结束条件，并有管理入口；任务管理器和音量合成器中，辅助进程的名称、描述和图标可辨认并归属本应用；辅助进程崩溃时主程序继续运行并提示。实现要点见附录 A。\
  常见问题：关闭应用后仍有六个 `node.exe` 在运行，用户无法判断属于哪个软件。
- [ ] **COMPONENT-04 第三方许可与权利说明** · 基线 — 应用内可找到随附组件和资源的版权与许可说明；GPL、LGPL 等许可要求提供源码时，有对应的获取方式。\
  常见问题：应用随附 FFmpeg 和字体，关于页面和安装包中都没有许可文本。

## MEDIA · 播放与采集

适用：在核心流程中播放、预览或采集音视频的产品，不限于专用播放器。设备变化后的恢复见 TASK-09，隐藏时的资源见 TASK-08，色彩见 DISPLAY-10，采集权限见 PRIVACY-01。MEDIA-06 适用于所有显示图片或视频的产品，MEDIA-07 适用于有全屏查看、放映或沉浸阅读模式的产品。

- [ ] **MEDIA-01 系统媒体控制与正在播放信息** · QoL — 持续播放可通过系统媒体控件和硬件媒体键控制（Windows SMTC、Linux MPRIS、macOS Now Playing），显示正确的内容和播放状态；不再播放时释放控制权。\
  常见问题：用户已切回音乐应用，按耳机播放键却重新播放了文档里的旧视频。
- [ ] **MEDIA-02 音量、混音与设备独占** · 基线 — 播放遵守系统静音和每应用音量，与其他应用的音频共存；独占设备或改变其他应用音频的行为由用户明确选择，独占失败时回退并显示真实状态。音频输入和输出可选跟随系统默认设备或固定某台设备。跟随时随系统默认设备切换，固定的设备断开后回退并标明。\
  常见问题：仅打开附件预览就独占了声卡，其他应用突然没有声音。
- [ ] **MEDIA-03 采集前的来源确认** · QoL — 开始录音、录像或通话前，用户可通过电平、画面预览或试录确认所选设备确实有信号。\
  常见问题：设备列表选中了麦克风，录完一小时才发现采集的是没有信号的虚拟输入。
- [ ] **MEDIA-04 实际采集状态与停止入口** · 基线 — 麦克风、摄像头、屏幕或系统音频正在被采集时，用户持续看到来源和状态，并可明确停止；停止后实际释放设备。用户从系统界面停止共享，或被共享的显示器断开时，应用中的状态随之变为已停止。\
  常见问题：界面显示已退出通话，辅助进程仍占用摄像头，指示灯持续亮着。
- [ ] **MEDIA-05 屏幕采集范围确认** · 基线 — 开始或切换屏幕采集前，用户确认采集的是窗口、应用还是整块显示器；目标窗口关闭后停止或重新选择，不自动扩大范围。共享整块屏幕期间，可以暂停本应用的通知横幅，共享结束后恢复。截图和录屏工具自身的选区框、倒计时和控制条默认不出现在结果中。\
  常见问题：被分享的窗口关闭后，应用自动改为采集整块屏幕，暴露了其他窗口。
- [ ] **MEDIA-06 内容方向与像素比例** · 基线 — 图片和视频按其旋转信息和像素比例正确呈现，预览与导出一致。\
  常见问题：手机竖拍的视频预览正常，导出后变成横向。
- [ ] **MEDIA-07 全屏与放映时的指针与控件** · QoL — 全屏观看、放映和沉浸阅读时，指针和浮动控件在一段无操作后自动隐藏，移动指针或按键即恢复；窗口模式下是否隐藏可单独设置；隐藏不影响键盘操作和辅助技术（见 A11Y-08）。\
  常见问题：全屏看视频时指针一直停在画面中央。

## TRANSFER · 传输结果的交付

适用：下载、上传、同步或获取大体积资源的产品。暂停与续传见 TASK-04，重试见 TASK-05，流量控制见 NETWORK-06，文件名处理见 FILE-03。

- [ ] **TRANSFER-01 传输完整性验证** · 基线 — 有校验信息（哈希、签名、长度）时，传输完成后据此验证；校验失败的文件不作为成功结果投入使用。\
  常见问题：下载显示完成但文件缺少部分内容，应用随即将损坏的模型加载为默认模型。
- [ ] **TRANSFER-02 未完成文件与正式结果的边界** · 基线 — 传输中的文件使用临时名称（例如 `.part`）；接收、组装和校验完成后才以正式名称出现，其他程序不会打开未写完的文件。\
  常见问题：下载一开始就出现正式文件名，另一个应用自动打开了尚未写完的文档。
- [ ] **TRANSFER-03 速率与并发控制** · QoL — 长时间或大批量传输提供总速率限制，并对全部并行任务生效；适用时上传与下载分别限制。限速是否作用于局域网内的传输，界面上可见、可选。\
  常见问题：每个任务都设了限速，十个任务同时运行仍占满连接。

## 附录 A · 实现要点

按条目 ID 列出需要额外注意的实现细节。

**通用**

- DATA-06、SETTINGS-04：写入同目录下的临时文件，对其执行 fsync，再原子替换目标文件。POSIX 使用 `rename`，随后对所在目录执行 fsync；macOS 上需要 `fcntl(F_FULLFSYNC)` 才能确保数据写入存储介质。Windows 先对临时文件调用 `FlushFileBuffers`，再用带 `MOVEFILE_REPLACE_EXISTING` 和 `MOVEFILE_WRITE_THROUGH` 的 `MoveFileEx` 替换；`ReplaceFile` 会保留原文件的属性，但其 `REPLACEFILE_WRITE_THROUGH` 标志在文档中标为不受支持。
- DATA-06（元数据）：替换前将原文件的权限、所有者和扩展属性复制到临时文件；原文件是符号链接时写入其目标。原文件有多个硬链接时，原子替换会使其他链接仍指向旧内容：要么原子替换并告知用户链接将断开，要么先完成备份再就地更新。Windows 上替换因共享冲突失败时短暂重试，安全软件、索引器和同步客户端会短时占用文件。
- DATA-05：SQLite 数据库使用 Online Backup API 或 `VACUUM INTO` 生成一致的副本；WAL 模式下只复制主数据库文件会遗漏尚未检查点的数据。
- INSTALL-07：更新包和版本清单都签名，公钥随应用分发，私钥离线保管并准备轮换方案；拒绝版本号低于当前版本的更新，除非用户明确选择回退。
- SYSTEM-12：Windows 在 `WM_QUERYENDSESSION` / `WM_ENDSESSION` 中快速保存；只在保存进行中调用 `ShutdownBlockReasonCreate` 并给出原因；用 `RegisterApplicationRestart` 在系统更新重启后恢复。macOS 在 `applicationShouldTerminate` 中保存，并支持登录时重新打开窗口。
- COMPONENT-03：Windows 用带 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` 的作业对象管理子进程；Linux 用 `prctl(PR_SET_PDEATHSIG)` 配合进程组；macOS 没有等价机制，由子进程监视父进程退出。子进程不继承不必要的句柄，否则作业对象无法结束它们。
- NETWORK-07：使用带 PKCE 的授权码流程；回调中的 `state` 与当前请求一致，重定向地址与登记的地址完全匹配；已使用或已过期的回调一律拒绝。
- PRIVACY-09：HTTP 和 WebSocket 服务只绑定回环地址，使用随机端口和访问令牌，并校验 Origin 和 Host；WebSocket 升级请求通常绕过 HTTP 中间件的 Origin 检查，需单独校验；允许的 Origin 不从 Host 头推导，否则可被 DNS 重绑定绕过。命名管道和 Unix 套接字的访问权限仅限当前用户，并在连接时校验对端进程的身份。
- TRUST-05：解包前规范化每个条目的目标路径，拒绝落在目标目录之外的条目和符号链接；签名校验在解包之前完成。
- WINDOW-05、MANAGED-02：Windows 单实例 mutex 使用 `Local\` 前缀按会话隔离，`Global\` 会阻止其他用户启动；macOS 的 `LSMultipleInstancesProhibited` 同样影响快速用户切换。
- INPUT-12：Windows 上手写笔有 Windows Ink 与 WinTab 两套接口，驱动或应用只支持其一时压感丢失（Krita 的 Tablet Settings、Blender 的 Tablet API 均提供切换）；WinTab 坐标在多显示器下按虚拟桌面映射，需校正。
- LOCALE-04：Node.js / Electron（ICU）和 JRE 内嵌时区数据库，随运行时版本而非操作系统更新；Python 的 `pytz` 内嵌数据库，`zoneinfo` 在系统没有时区数据时（Windows）回退到 `tzdata` 包，二者都随依赖版本更新。Windows 自身的时区数据经 Windows Update 更新。优先使用系统时区数据，或随版本更新内嵌数据并显示数据版本。
- INSTALL-02：Windows Installer 以 UpgradeCode 识别同一产品族，改名后沿用原 UpgradeCode；ProductCode 按大版本升级规则变化，二者不能混为一个"永不改变"的标识。Electron 的 `userData` 默认路径由应用名决定，改名前用 `app.setPath('userData', …)` 固定原目录。macOS 的钥匙串访问和隐私授权按代码签名的 designated requirement 识别，更换 Team ID 或 Bundle ID 会使之失效。
- INSTALL-04：Sparkle 的更新源可用 `sparkle:minimumSystemVersion` 和硬件要求筛掉当前系统不兼容的版本；自行实现的更新器在清单中写明每个版本的最低系统和架构。
- TRUST-07：WebView 转发给主窗口的键盘和鼠标事件只用于焦点和快捷键提示，不执行命令；新出现的确认界面在短暂延迟内忽略输入（Chromium 的 `InputEventActivationProtector` 约为 500 ms）。
- NETWORK-02：重试使用退避加随机抖动；只在一层重试，请求库、业务层和任务队列各自重试会把请求量成倍放大；停止任务时一并取消已排定的重试计时器。
- NETWORK-07：macOS 使用 `ASWebAuthenticationSession`；Windows 使用系统浏览器加回环地址或自定义协议回调，或使用 Web Account Manager（WAM）。RFC 8252 要求原生应用通过外部 user-agent 发起授权。
- MANAGED-02：Windows 上设置写入 `FOLDERID_RoamingAppData`，可重建的缓存、日志和索引写入 `FOLDERID_LocalAppData`。Electron 默认把 `sessionData`（含 Chromium 磁盘缓存）放在 `userData` 下，即 Roaming；在 `ready` 之前用 `app.setPath('sessionData', …)` 移到 Local。
- DATA-17：许多加密方案的口令只用来包裹数据密钥，改口令不会重新加密数据和数据密钥，旧备份配合旧口令或旧密钥材料仍能解开。临时副本的覆盖删除在 SSD、文件系统快照、同步副本和备份中不保证不可恢复，说明保护范围时不要写成安全擦除。
- LOCALE-03：表格类产品复制到剪贴板时，可以同时提供显示文本和完整精度的数值格式（例如 HTML 或应用私有格式），由目标应用选择。
- SETTINGS-04：设置的存放位置：Windows 为 `%APPDATA%` 或注册表，macOS 为 `~/Library/Application Support` 或 plist，Linux 为 `$XDG_CONFIG_HOME`。
- SYSTEM-03：Windows 按 AppUserModelID 判断系统通知的来源。未注册 AppUserModelID 的进程（例如开发版、便携版）发出的通知会显示为来自其他程序。需注册该 ID，并提供带有此 ID 的开始菜单快捷方式。
- PRIVACY-10：Windows 用 `ExcludeClipboardContentFromMonitorProcessing`、`CanIncludeInClipboardHistory`、`CanUploadToCloudClipboard` 三种格式标记剪贴板监视程序应跳过的内容，macOS 用 `org.nspasteboard.ConcealedType`。向剪贴板写入敏感内容的应用设置这些格式，记录剪贴板的应用读取并遵循它们。
- TRUST-04：按 Unicode UTS #39 的混合字母与易混淆字符规则判断是否以 Punycode 显示域名，或沿用浏览器的 IDN 显示策略。
- INPUT-24、INPUT-07：macOS 上 ⌘C、⌘V、⌘A、⌘Z 经主菜单"编辑"菜单中的项分发给响应链。只有菜单栏图标、不显示主菜单的应用，需要安装含编辑项的主菜单，或在面板中把这些组合键转给主菜单。
- SYSTEM-17：Windows 上进程和快捷方式设置同一个 AppUserModelID；只有需要多个版本并存时才在 ID 中加入版本信息，否则省略，升级后的版本沿用同一个 ID。按版本目录安装的更新器（例如 Squirrel）在更新后改写快捷方式的目标。Linux 上 `.desktop` 文件名、`StartupWMClass`、X11 的 `WM_CLASS` 与 Wayland 的 `app_id` 一致，图标以同名安装到 hicolor 主题；Flatpak 下 `app_id` 即应用 ID。
- WINDOW-01：Windows `GetWindowPlacement` 返回的位置可能是工作区坐标，不能直接传给 `SetWindowPos`。左侧或上方显示器上的窗口坐标为负，校验时不拒绝负值。常规尺寸与最大化状态分开保存。
- WINDOW-04、WINDOW-05：单写入者锁在打开存储、执行迁移和启动后台写入之前取得，持有到全部写入停止；不删除或替换正在使用的锁文件。转发启动请求与持有所有权分开，转发失败时不静默打开第二个写入者。
- DATA-02：持续输入时自动保存的等待有上限，每次按键都重新计时的防抖会让检查点无限推迟。提交、完成或替换会话后取消旧的计时器，避免恢复已完成的草稿。
- DATA-12、TASK-13：预览按显示尺寸乘以像素比解码。1200 万像素的图片仅像素缓冲就约 48 MB，压缩后的文件大小不代表内存峰值。限制同时进行的解码数。
- TASK-07：macOS 辅助功能接口的默认消息超时为 6 秒，启动时用 `AXUIElementSetMessagingTimeout` 调低，并在后台队列调用。调用外部命令时同时读取标准输出和标准错误，否则输出塞满管道后子进程挂起。
- TASK-09：超时、重试退避和持续时间用单调时钟计算，并明确是否计入睡眠：Windows `QueryUnbiasedInterruptTime` 不计入睡眠；Linux `CLOCK_BOOTTIME` 计入、`CLOCK_MONOTONIC` 不计入；Apple `mach_continuous_time` 计入、`mach_absolute_time` 不计入。需要跨重启的期限保存为绝对时间，启动时重新计算剩余时间，已到期的只处理一次。
- HELP-05：错误钩子在应用启动前初始化，否则漏掉启动阶段的崩溃。每个发行版本存档调试符号（PDB、dSYM、分离的调试文件），按 PDB 的签名（GUID）与 age、Mach-O 的 UUID、ELF 的 build ID 与最终发行包中的二进制核对；同一份源码重新构建得到的符号不一定匹配。
- COMPONENT-01：macOS 和 Linux 上从图形界面启动的进程不读取 shell 配置文件，PATH 只有系统默认值。可在启动时以交互登录 shell 运行一次取得用户环境（例如 `$SHELL -ilc env`），设置超时并缓存结果，同时允许用户指定工具路径。
- WINDOW-10：临时写入剪贴板的内容，在 macOS 上加 `org.nspasteboard.TransientType`；在 Windows 上加 `ExcludeClipboardContentFromMonitorProcessing` 格式，或把 `CanIncludeInClipboardHistory` 设为 0。保存和恢复原内容时遍历全部格式，延迟渲染的格式先取出数据。
- PRIVACY-10：macOS 每次按键时检查 `IsSecureEventInputEnabled()`；Windows 可经 UI Automation 读取焦点控件的 `IsPassword` 属性。结果为真时不显示、不记录该按键。
- PRIVACY-02：macOS 的辅助功能、屏幕录制等授权按代码签名和安装路径记录。临时签名（ad hoc）每次构建都变，授权随之失效，而系统设置中的开关仍显示已开启；开发构建同样用固定证书签名，并安装到固定路径。开关显示已开启而接口仍失败时，从列表移除应用后重新添加。
- PRIVACY-01、SYSTEM-03：通知授权请求在无人操作时弹出，可能被系统记为拒绝，此后请求一直失败。只在用户触发相关功能时请求，并在设置中显示授权状态和打开系统通知设置的入口。
- SYSTEM-03：Windows App SDK 的 `AppNotificationManager.Default.Register()` 也可供非打包应用注册通知，调用进程注册为 COM 服务器。Linux 通知服务器可能忽略动作按钮；服务器不支持 `body-markup` 时，客户端自行去掉标记。依赖动作按钮的操作在应用内保留入口。
- SYSTEM-02：macOS 菜单栏中显示实时文字时，按可能出现的最宽文字定宽，并使用模板图像，避免每次刷新推挤相邻图标。
- SYSTEM-08：macOS 新建电源断言前释放旧断言，泄漏的断言会让电脑在开关显示关闭后仍不睡眠。阻止显示器睡眠的断言不阻止合盖睡眠，防睡眠工具在界面上说明这一点。
- SYSTEM-13：修改前读取原值时，区分"未设置"与"设为默认值"。原本未设置的项，恢复时删除该项，不写入一个显式值。
- LOCALE-01：macOS 本地化应用名需要 `LSHasLocalizedDisplayName`、`CFBundleLocalizations` 和各语言的 `InfoPlist.strings`，并让应用包的文件名与 `CFBundleName` 一致。
- INSTALL-07：Sparkle 比较 `CFBundleVersion`，构建号须单调递增。DMG 先公证装订，再用 `sign_update` 签名，顺序相反时签名失效。EdDSA 私钥丢失后已安装的副本无法再自动更新，私钥离线备份。
- INSTALL-10：从 DMG 或下载目录直接运行时，macOS 对应用做路径随机化（App Translocation），更新器无法替换程序，登录项也会指向临时路径。
- INPUT-09、INPUT-10：macOS 14 起，应用读取其他开发者应用的数据容器中的文件时，系统向用户请求许可，授权持续到应用退出。经剪贴板或拖放接收其他应用的内容时，优先使用数据表示或文件承诺（file promise），不直接按路径读取对方容器中的文件。
- INPUT-09、INPUT-13：工具包在 Flatpak 沙箱应用之间拖放文件时使用 FileTransfer 门户（`application/vnd.portal.filetransfer`），会话默认（`autostop`）在第一次 `RetrieveFiles()` 后关闭。macOS `NSItemProvider.loadFileRepresentation` 写出的临时文件在回调返回时删除，需要在回调内复制。
- FILE-03：Windows 长路径依赖系统设置和应用清单中的 `longPathAware`；核对编译后可执行文件内嵌的清单，不只看源 XML。自带扩展路径支持的运行时不需要此清单。
- SYSTEM-05：Windows 上文件类型的图标由 ProgID 下 `DefaultIcon` 的默认值指定，类型名称写在 `FriendlyTypeName`（间接字符串 `@文件,-资源号`），同时为兼容设置 ProgID 的默认值。macOS 11 起在 `UTExportedTypeDeclarations` 中声明自有类型，`UTTypeDescription` 为可本地化的类型名称，`UTTypeIcons` 指定背景、中心徽标和底部文字，由系统合成文档图标，徽标省略时使用应用图标。Linux 上随包安装 shared-mime-info 的 XML 并运行 `update-mime-database`，`<comment>` 为类型名称；图标以 MIME 类型把"/"换成"-"后的名称安装到图标主题，随包 XML 中的 `<icon>` 不生效。
- SYSTEM-18：Windows 上缩略图、预览窗格和详细信息分别由缩略图处理程序（`IThumbnailProvider`）、预览处理程序（`IPreviewHandler`）和属性处理程序（`IPropertyStore`）提供，全文索引用 `IFilter` 或属性处理程序。这些处理程序默认在隔离进程中运行（预览处理程序由 `prevhost.exe` 承载），优先实现 `IInitializeWithStream`，不设置 `DisableProcessIsolation`。macOS 10.15 起用 Quick Look 的缩略图扩展（`QLThumbnailProvider`）和预览扩展，macOS 15 正在移除对 `.qlgenerator` 插件的支持；Spotlight 索引仍用 `.mdimporter` 插件。Linux 上 GNOME 读取 `thumbnailers/` 目录中的 `.thumbnailer` 文件，KDE 使用 `KIO::ThumbnailCreator` 插件，KF 6.6 起也读取 `.thumbnailer` 文件。生成失败按 Thumbnail Managing Standard 记录在 `fail/` 目录下，不反复重试。
- SYSTEM-19：Windows 11 的第一级右键菜单只显示具有包标识的应用（MSIX 打包，或非打包应用使用带外部位置的包）通过 `IExplorerCommand` 提供的命令，旧式外壳扩展出现在"显示更多选项"中。"新建"菜单项来自扩展名键下的 `ShellNew`（`NullFile`、`FileName`、`Data` 或 `Command`），菜单中的名称取自 ProgID 的类型名称。
- SYSTEM-09：Windows 上作为分享目标需要包标识，在清单中声明 `windows.shareTarget`，非打包应用可使用带外部位置的包；PWA 在 Web 应用清单中声明 `share_target`。macOS 通过共享扩展接收。
- INSTALL-06：Windows Installer 把 `DisplayName`、`DisplayVersion`、`Publisher`、`EstimatedSize`、`UninstallString`、`ModifyPath` 等写入 `Uninstall\<ProductCode>` 键；自制安装程序写入同样的值，更新时同步改写 `DisplayVersion` 和 `EstimatedSize`。卸载时一并注销缩略图、预览、属性处理程序和 `ShellNew` 项，并以 `SHChangeNotify(SHCNE_ASSOCCHANGED, …)` 通知外壳刷新图标。
- DATA-16：执行时以预览时记录的版本（修改时间与大小、内容哈希或服务端版本号）为条件，不符则跳过该项；后台刷新不替换这一依据。Git 的 `--force-with-lease` 是同类做法：只有远端仍是预期的值时才覆盖，不显式给出预期值时，后台 fetch 可能使保护失效。
- NETWORK-11：Windows 存储感知不回收用户设为"始终保留在此设备上"的云文件。作为同步客户端时，离线保留使用 Cloud Files API 的固定状态（`CF_PIN_STATE_PINNED`，任何应用都可以通过 `CfSetPinState` 设置），平台拒绝对已固定的占位文件执行脱水。
- TRUST-09：LibreOffice 24.2.5 和 24.8.0 起，在修复模式下把文档中的所有签名视为无效（CVE-2024-7788）。
- TRUST-10：解压前按归档声明的字典大小和解压后的总体积检查上限；图像解码前读取头部声明的尺寸，按像素数而不是文件大小估算内存；嵌套归档、XML 实体、引用展开等递归处理设置深度和累计输出的上限。7-Zip 24.03 起，图形界面在 RAR 字典大于 4 GB 时先征得用户同意；WinRAR 7.00 起，字典超过设置中的上限时提示取消或继续。上限的数值由产品决定。

**Electron / Chromium**

- INPUT-06：`keydown` 处理中检查 `isComposing`（或 keyCode 229），组合期间不响应 Enter 等提交键。只拦截提交键；对 keyCode 229 一律直接返回会同时拦截 Ctrl 组合键和 Esc。
- APPEARANCE-07：非正文区域设置 `user-select: none`，正文和需要复制的信息除外；生产环境中按业务需要处理 Ctrl/Cmd + R、F5、Ctrl/Cmd + P 的默认行为；外部链接通过 `shell.openExternal` 打开；移除默认的"检查元素"菜单。
- DISPLAY-08：创建窗口时按当前主题设置 `backgroundColor`，并使用 `show: false` 配合 `ready-to-show` 事件显示窗口。
- SYSTEM-02：Linux 托盘依赖 StatusNotifierItem，GNOME 默认不显示，需要 AppIndicator 扩展；提供无托盘时的替代入口。
- SYSTEM-04：检查 `globalShortcut.register` 的返回值；快捷键已被占用时注册失败，且不抛出异常。
- WINDOW-02：自绘标题栏会失去 Windows 11 贴靠布局菜单，需使用 `titleBarOverlay` 或自行处理命中测试。
- TASK-08：检查 `backgroundThrottling` 设置、隐藏时的渲染循环，以及多个渲染进程的常驻内存。
- NETWORK-05：`net.fetch` 使用 Chromium 网络栈并跟随系统代理，Node.js 的 `fetch` 不使用系统代理；两者混用时代理行为不一致。
- PRIVACY-03：`safeStorage` 在 Linux 上的保护程度取决于 secret store 后端，`basic_text` 后端不提供有效保护；可用 `safeStorage.getSelectedStorageBackend()` 检测当前后端。
- DISPLAY-03：Linux Wayland 下的分数缩放依赖 Ozone 相关启动参数，需实测。
- INSTALL-07：electron-updater 在 Windows 上通过 `verifyUpdateCodeSignature` 校验发布者名称；6.3.0-alpha.6 之前的默认校验可被篡改的清单绕过（CVE-2024-39698）。macOS 的 Squirrel.Mac 要求应用已签名。
- INPUT-19：Web 技术栈在 `keydown` 和 `keyup` 上都读取 `getModifierState('CapsLock')`；macOS 关闭大写锁定时只产生 `keyup`，只监听 `keydown` 会让提示残留。
- TRUST-07：保持开启 `contextIsolation` 和 `sandbox`，关闭 `nodeIntegration`，为渲染外来内容的视图设置内容安全策略（CSP）。Joplin 的 CVE-2024-49362 中，相反的设置加上没有沙箱的预览 iframe，使笔记中的一个链接变成了命令执行。
- A11Y-03、INPUT-20：界面语言变化时更新 `<html lang>`，多语言内容按段落标注 `lang`。屏幕阅读器的发音、拼写检查、断字和中日韩字形的选择都依赖它。
- INPUT-24：macOS 上在应用菜单中定义带 `role` 的编辑菜单（`role: 'editMenu'`，或逐项使用 `copy`、`paste` 等角色），否则文本框中的 ⌘C、⌘V 无效。不显示菜单栏的窗口同样需要这个菜单。
- A11Y-03、AUTOMATE-02：Electron 默认不启用 Chromium 的无障碍支持，检测到辅助技术时才启用，语音控制、UI 自动化测试和读取无障碍树的 Agent 可能读不到界面。可在 `ready` 之后调用 `app.setAccessibilitySupportEnabled(true)`，或在设置中提供开关。

**Tauri / 系统 WebView**

- Windows 依赖 WebView2 运行时（Windows 11 自带，Windows 10 可能需要安装）；Linux 使用 WebKitGTK，需实测其渲染性能、分数缩放和所用 Web API 的支持情况，对应 DISPLAY 和 TASK-07。
- 托盘属于核心功能（`tray-icon` 特性），全局快捷键、单实例、开机启动和更新器由插件提供；各平台行为差异较大，SYSTEM 整节需逐条验证。
- SYSTEM-01：Flatpak 包的自启动项通过 Background 门户注册，自启动条目的执行命令为 `flatpak run <应用 ID>`，而非沙箱内的可执行文件路径。
- 三个平台的 WebView 内核不同，CSS 和字体渲染存在差异，APPEARANCE-03 和 TYPO-01 需在三个平台分别检查。
- INSTALL-07：updater 插件强制签名验证，公钥在 `plugins.updater.pubkey`；私钥丢失后已发布的版本无法再自动更新。updater 2.12.0 之前只签二进制不签清单，可被诱导降级（CVE-2026-95625）；升级并启用版本签名。
- TRUST-07：通过 capabilities 限制前端可调用的命令，外来内容在无法调用这些命令的视图中渲染。

**Qt**

- DISPLAY-01、DISPLAY-03：Qt 6 默认启用高 DPI 缩放，分数缩放的取整策略需通过 `QGuiApplication::setHighDpiScaleFactorRoundingPolicy` 设定；Wayland 与 X11 行为不同。
- APPEARANCE-01：Windows 深色模式的自动跟随依赖较新的 Qt 6 版本；旧版本的 Fusion 样式不会自动跟随。
- INPUT-06：Wayland 下输入法依赖 text-input 协议，fcitx5 等需实测。
- DATA-06：`QSaveFile` 提供"写入临时文件后提交"；启用 `setDirectWriteFallback(true)` 后，无法创建临时文件时会直接覆写目标文件。
- DATA-07：`QFileSystemWatcher` 在文件被删除或重命名后停止监听；其他程序以替换方式保存后，需重新添加路径。

**Flutter 桌面**

- A11Y-03：标准组件自带语义信息；自绘或自定义组件需通过 `Semantics` 组件显式提供。
- INPUT-06、INPUT-07：桌面端的文本输入和输入法需重点测试。
- INPUT-01：原生菜单栏仅 macOS 提供 `PlatformMenuBar`，Windows 和 Linux 需自行绘制。
- WINDOW 整节依赖第三方窗口管理插件。
- DATA-02：`AppLifecycleState.paused` 只在 iOS 和 Android 上出现，`detached` 只在 iOS、Android 和 Web 上出现。桌面上失去焦点但仍有可见窗口时为 `inactive`，最小化或切到其他虚拟桌面时为 `hidden`。不依赖 `paused` 或 `detached` 保存；`AppLifecycleListener.onExitRequested` 只在退出可以取消时调用，也不能作为唯一的保存时机。
- WINDOW-03：Dart 的 `Future.timeout` 只停止等待，不取消原操作，超时的保存或释放仍可能在之后修改状态。各个退出入口共用同一次退出流程的结果。
- WINDOW-04：`RandomAccessFile.lock` 在 Linux 和 macOS 上是按进程生效的建议锁：进程关闭该文件的任何一个描述符时，所有锁都被移除；同一进程中的多个 isolate 可以同时持有排他锁。Windows 上锁属于获取它的句柄。用独立进程测试，不能只用 isolate。
- HELP-05：`firebase_crashlytics` 只支持 Android、iOS 和 macOS，Windows 和 Linux 需要另接崩溃上报。

**原生框架（WinUI / WPF / AppKit / GTK）**

- WPF：按显示器 DPI 感知需在应用清单中声明。
- WinUI 3：打包与非打包分发在开机启动、文件关联和通知注册上路径不同，INSTALL 和 SYSTEM 按分发方式分别验证。
- AppKit / SwiftUI：沙箱下访问文件需使用安全作用域书签，FILE-01 的最近文件持久化书签而非路径；最后一个窗口关闭后是否退出由 `applicationShouldTerminateAfterLastWindowClosed` 决定。
- INSTALL-07：macOS 常用 Sparkle，更新包需 EdDSA 签名，公钥在 Info.plist 的 `SUPublicEDKey`，仅 DSA 已不受支持；Windows 可用 WinSparkle；MSIX 分发时由 App Installer 处理更新。
- GTK：深色模式通过桌面门户读取；无障碍通过 AT-SPI 实现；Wayland 分数缩放的支持情况因 GTK 版本而异。
- Linux 通用：登录启动、全局快捷键和文件选择在沙箱下通过 XDG Desktop Portal 实现，需处理后端支持情况、用户拒绝和最终打包身份。
- WINDOW-03：SwiftUI 中 `WindowGroup` 在最后一个窗口关闭后保持应用运行；`Window` 是应用唯一的场景时，关闭窗口即退出。
- SYSTEM-11：SwiftUI 中只在菜单栏显示的应用（`MenuBarExtra` 是唯一场景），用户把菜单栏项移除后，应用自动退出。
- A11Y-03：SwiftUI 的 `accessibilityInputLabels` 为控件设置供语音控制和全键盘控制使用的替代名称。可见文字含动态数值的按钮和列表项（计数、计时）用它提供稳定的名称，用户不必读出当前数值即可操作。
