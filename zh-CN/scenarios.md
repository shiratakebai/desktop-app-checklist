# 走查场景

[English](../scenarios.md) | 简体中文

组合场景同时涉及多个条目及其之间的衔接，比逐条勾选更容易发现问题。需要验证清单时，从本文件中选择与产品相关的场景，在真实环境中执行。

**执行原则**：按产品选择场景，无需覆盖平台、设备与输入法的全部组合。涉及强制结束进程、断开存储、覆盖、迁移或卸载的场景，使用可丢弃的样本和隔离环境。记录时区分两种情况：仅看到实现线索，或已在所述环境中实际测试。无法实测的项目标注"未验证"。

每个场景列出操作步骤、检查点和相关条目。

**按用户时刻挑选**：下表按用户所处的时刻给场景分组，便于检查哪类时刻还没有走查过。分组只为方便挑选，与优先级无关。一个场景可出现在多个时刻下。

| 时刻 | 场景 |
| --- | --- |
| 首次使用 | S21、S23、S27、S40 |
| 中断 | S05、S10、S32 |
| 离开 | S09、S11、S20、S41 |
| 返回 | S04、S26、S34、S41 |
| 误操作 | S42 |
| 环境变化 | S02、S07、S08、S12、S15、S16、S18、S22、S28、S29、S30、S33、S38 |
| 系统异常 | S06、S13、S17、S31、S37 |
| 重复劳动 | S19、S25 |
| 更新之后 | S14、S24 |
| 迁入 / 并用 | S43 |

S01、S03、S35、S36、S39、S44 检验的是任何时刻都应成立的性质（输入法、无障碍、本机接口安全、外来内容、多语言输入、换一种语言查找），不归入上表。

### S01 · 中文或日文输入法：确认候选词后测试保存、撤销和 Esc

开启中文或日文输入法，在输入框中输入拼音或假名，按 Enter 确认候选词；确认后输入法仍开启但不在组合中，此时按 Ctrl/Cmd + S、Ctrl/Cmd + Z 和 Esc。再输入一段拼音或假名，在候选窗打开时按 Esc。

检查点：按 Enter 未提交内容；候选窗紧贴插入点；确认后的快捷键和 Esc 正常生效，未被输入法处理逻辑拦截；组合中按 Esc 只取消组合，未关闭对话框或面板。

相关条目：INPUT-06 输入法组合输入；INPUT-01 平台标准快捷键与键盘布局；INPUT-02 对话框约定

### S02 · 放大文字、半屏贴靠、拔出扩展坞

将系统文字放大到 125% 以上，把窗口贴靠到笔记本屏幕的一半，再将窗口移到外接显示器，然后拔出扩展坞。

检查点：主窗口、弹窗、菜单和关键按钮仍可找到并操作；窗口回到可见区域；贴靠布局菜单可以唤出，选择后窗口能放入对应区域。

相关条目：DISPLAY-01 系统缩放；DISPLAY-02 运行时显示配置变化；DISPLAY-03 混合 DPI；DISPLAY-04 窗口尺寸适应；DISPLAY-06 文字放大与长文本重排；WINDOW-01 位置与尺寸恢复；WINDOW-02 窗口状态恢复与系统窗口管理；WINDOW-12 从属窗口的位置与层级

### S03 · 仅用键盘和屏幕阅读器完成核心流程

不使用鼠标，开启 NVDA、讲述人、VoiceOver 或 Orca，完成"启动 → 打开或新建 → 核心操作 → 保存 → 关闭"。过程中进入并退出一次编辑区，关闭一个对话框。最后开启语音控制（Windows 语音访问、macOS 语音控制），说出屏幕上的文字点击一个按钮。

检查点：每一步的对象和状态可被理解；不存在键盘陷阱；关闭对话框后焦点回到触发它的控件；语音控制可按屏幕上的文字点击按钮。

相关条目：A11Y-01 核心流程可用键盘完成；A11Y-02 焦点可见、顺序合理、关闭后焦点返回；A11Y-03 辅助技术语义；A11Y-04 状态变化可播报；INPUT-02 对话框约定

### S04 · 筛选列表、打开详情、返回，再触发后台刷新

在列表中输入筛选词、排序并多选几项，打开其中一项的详情，返回列表；开始重命名其中一项，在输入过程中触发一次自动刷新或同步。

检查点：筛选词、排序、选中项、滚动位置和树展开状态保持不变；刷新未改变指针下的目标；正在重命名的输入未丢失。

相关条目：WINDOW-06 工作区与视图上下文恢复；DISPLAY-08 无闪烁、无跳动、操作目标稳定；INPUT-11 多选与批量操作；DATA-03 未保存更改保护

### S05 · 请求乱序返回与切换账号

通过限速或断点使搜索 A 的响应晚于搜索 B 返回；在联网产品中切换账号，然后让旧账号的一个请求完成；最后发起一次搜索，在结果返回前关闭窗口。

检查点：界面显示 B 的结果；旧账号的响应未进入新账号的界面；窗口关闭后未弹出旧结果。

相关条目：TASK-11 过期结果不覆盖当前操作；PRIVACY-05 退出与切换账号或工作区

### S06 · 保存时目录不可写或磁盘已满；单独测试强制结束进程

使用样本文档，将目标目录设为只读或填满磁盘后保存；恢复条件后重试。另起一轮：编辑到自动保存触发之后，强制结束进程并重新启动。

检查点：原文件未被截断为 0 字节；内存中的内容仍在，可另存；强制结束后恢复的是最近一次自动保存，恢复界面显示了对应时间。两类测试分别记录；强制结束进程不能模拟断电。

相关条目：DATA-06 安全写入；DATA-02 自动保存与崩溃恢复；DATA-01 保存状态可见；HELP-03 错误信息可操作、可复制

### S07 · 外部程序替换保存与重命名；离线打开云盘占位文件

用另一个编辑器对已打开的文件连续保存多次（多数编辑器采用"写入临时文件后重命名"），然后重命名该文件，再改回原名。另取一个 OneDrive 或 iCloud 的仅联机文件，断网后在应用中打开，再对整个目录建立索引。

检查点：每次外部保存都被检测到，而不仅是第一次；重命名后应用能跟踪文件位置或提供重新定位；占位文件未被误报为损坏，未出现无反馈的阻塞，未触发大量下载。

相关条目：DATA-07 外部变化与冲突；FILE-05 网络驱动器、可移动介质与云盘占位文件；FILE-04 移动、重命名与删除的反馈

### S08 · 两个客户端离线修改同一内容后联网

两台设备或两个账号同时离线，分别修改同一文档的不同位置和同一位置，然后联网。附件和配置也各修改一份。

检查点：冲突被显示，两个版本均可找回；附件和配置的冲突处理方式与文本分别检查；联网前可看到待同步队列。

相关条目：DATA-07 外部变化与冲突；NETWORK-04 待同步队列可见；DATA-05 历史版本与备份

### S09 · 关闭通知、热键冲突、托盘不可用时找回后台工具

在系统中关闭应用通知；用另一个程序占用应用的全局热键；在没有托盘的桌面（未安装扩展的 GNOME）上启动应用。

检查点：设置页未将热键显示为已生效；仍可通过应用图标、菜单或命令行重新打开和退出；进程始终可找到、可结束。

相关条目：SYSTEM-04 全局快捷键；SYSTEM-02 托盘或菜单栏入口；SYSTEM-11 系统能力不可用时的替代入口；SYSTEM-03 系统通知与注意力

### S10 · 长任务的取消、睡眠、网络切换与中断

启动下载、转换或录制，中途取消一次；再次启动，合盖睡眠数分钟后唤醒；再次启动，切换 Wi-Fi 或开关 VPN。最后强制中断一次录制或生成任务，用下游软件打开产物。

检查点：取消后中间产物的去向明确；唤醒和网络切换后任务继续或明确失败，未连续弹出错误；任务结束后释放阻止睡眠的请求；中断产物的主体可用性和附属信息分别有说明。

相关条目：TASK-03 停止等待、取消任务与撤回结果；TASK-09 睡眠唤醒、网络与设备变化；TASK-12 长任务中断后的产物；SYSTEM-08 阻止睡眠；TASK-05 失败重试与幂等

### S11 · 多来源拖入；关闭来源后粘贴；先后复制敏感值与普通文本

分别从文件管理器、邮件客户端、截图工具和浏览器拖入内容，并取消一次拖放；在应用中复制一段内容，关闭窗口或退出应用后到其他程序中粘贴；复制密码或令牌 A，等待清除时间到达；再复制 A，接着在其他软件中复制普通文本 B，等待清除时间到达。

检查点：各来源的拖入都有反馈，不支持的来源有说明；来源关闭后仍可粘贴；接收方获得的格式正确（纯文本编辑器、文档编辑器和聊天软件各测试一次）；第一轮中 A 已被清除；第二轮中 B 仍在剪贴板中。

相关条目：INPUT-09 拖入；INPUT-10 剪贴板格式与生命周期；INPUT-13 拖出；INPUT-21 应用内拖动的过程与结束；PRIVACY-07 敏感内容的显示与复制

### S12 · 项目迁移到新磁盘、新用户名和新设备；大小写冲突的文件名

将项目目录及其引用的图片、附件和字体整体移动到另一个磁盘或另一台用户名不同的计算机。在目录中放入 `Readme.md` 和 `readme.md`，同步到不区分大小写的文件系统。

检查点：资源可重新定位，定位一次即可修复同一批资源，缺失资源的记录未被删除；仅大小写不同的文件未被静默覆盖，处理方式明确。

相关条目：DATA-11 外部资源重新定位；DATA-09 数据位置透明、可迁移；FILE-03 路径、字符与命名冲突

### S13 · 编辑过程中备份并在空目录恢复；导出复杂工程

在有编辑活动时使用应用的备份功能导出，复制到空目录或另一台计算机恢复。另将一个多图层或多工作表的工程导出为开放格式，用目标软件打开。

检查点：恢复的数据包含最近的修改和附件，运行中的数据库通过备份接口导出；导出前说明了范围和损失；用户可区分完整工程与交付结果。

相关条目：DATA-05 历史版本与备份；DATA-08 导入导出与数据可迁移

### S14 · 使用最终发行包升级；回退到旧版本打开数据副本

用实际分发的安装包从上一版本升级，注销后重新登录，检查自启动、文件关联、最近文件和沙箱授权。然后在数据副本上安装旧版本并打开。另用一份会使数据迁移失败的数据副本升级一次。

检查点：升级后注册项和授权正常；迁移失败时数据回到升级前的状态；旧版本打开新数据时明确拒绝、只读打开或进入恢复流程，数据未损坏；无法安全降级时说明了原因。

相关条目：INSTALL-05 程序回滚与数据回退；SETTINGS-08 升级迁移；SYSTEM-01 登录时启动；FILE-01 平台文件对话框与持久授权；DATA-10 大范围删除与迁移的保护

### S15 · 切换键盘布局；用方向键浏览远程加载的项目

将键盘布局切换为非美式布局（德语、法语或日语），测试标点类快捷键和普通字符输入。在列表或标签之间仅用方向键移动，每一项的内容需远程加载。

检查点：快捷键按当前布局显示并可触发；方向键浏览未触发外部操作或不可逆的更改；随选择加载的预览未阻塞继续移动。

相关条目：INPUT-01 平台标准快捷键与键盘布局；INPUT-17 浏览与激活分离；INPUT-04 快捷键可自定义

### S16 · 在另一台设备上修改设置后同步

对提供设置同步的产品：在台式机上修改一个本地路径、一个设备选择和一个快捷键，然后在笔记本上查看。

检查点：机器相关的值未相互覆盖；各平台的快捷键分别保留；凭据未被同步。

相关条目：SETTINGS-06 配置可导出、可编辑、可同步；SETTINGS-05 作用域明确

### S17 · 临时禁用扩展排查问题，恢复后导出诊断包

安装一个会出错的插件或破坏布局，用安全模式或临时隔离启动确认问题，然后退出临时模式回到原环境。导出诊断包，解压后审阅。

检查点：临时模式未修改原配置；排查结束后插件状态恢复；诊断包说明了组成内容，发送前可预览；文件名、路径和个人词典中的测试敏感标记未出现在包中。

相关条目：HELP-07 安全模式与自助恢复；HELP-05 诊断日志与诊断包；SETTINGS-07 按类别重置

### S18 · 代理环境下登录、下载和更新；取消一次认证

在受支持的代理环境中，依次执行登录、调用核心 API、加载图片、下载文件和检查更新。中途取消一次浏览器登录，再完成一次完整登录。

检查点：每条路径都经过代理，失败时说明是哪个服务；取消登录后回到原界面，输入未丢失；登录完成后回到正确的窗口和任务。

相关条目：NETWORK-05 代理与企业网络；NETWORK-07 登录回调；NETWORK-01 连接状态

### S19 · 连续的成功操作与重复失败

连续批量保存二十次；让重连连续失败十次；重复执行一个会产生相同错误的操作。

检查点：成功反馈轻量且局部，未出现二十个 toast；失败提示被合并，重要的提示在 toast 消失后仍可找到并提供可执行的操作。

相关条目：SYSTEM-03 系统通知与注意力；HELP-03 错误信息可操作、可复制；WINDOW-08 不抢占焦点

### S20 · 隐藏空闲后的资源占用

将窗口最小化或隐藏到托盘，放置三十分钟。另在窗口可见但无操作的状态下放置十分钟。

检查点：CPU 占用接近零，内存未持续增长，无无意义的磁盘和网络活动；无必要的动画和轮询已停止或降低频率。资源预算由产品自定，监控类产品的必要消耗除外。

相关条目：TASK-08 空闲资源预算；SYSTEM-02 托盘或菜单栏入口

### S21 · 打开来源不明的工程：先只读查看，再放行

从网上下载一个包含构建脚本或宏的工程或文档，直接打开并阅读内容；然后放行一次；再打开同一目录下的另一个新文件。

检查点：打开时未执行任何脚本，界面说明了哪些能力已暂停；放行时说明了范围是本次、本文件还是本目录；同目录的新文件未被连带放行，除非放行时已说明范围是本目录；悬停在文档中的外部链接上可看到真实目标。

相关条目：TRUST-01 陌生内容先以受限模式查看；TRUST-02 放行范围明确；TRUST-04 链接目标可核验

### S22 · 许可到期且旧设备已不可用

使用已到期的试用或订阅账号启动；再模拟许可服务器不可达；最后在新设备上激活，旧设备不可用。

检查点：到期后仍可查看和导出自己的工作，并知道哪些部分无法导出；服务器不可达时区分了网络故障与许可失效，未在保存过程中关闭应用；新设备可通过远程解绑或客服途径完成激活。

相关条目：LICENSE-01 许可状态与可用范围；LICENSE-02 到期后取回已有工作；LICENSE-03 验证失败的处理；LICENSE-04 更换设备与设备丢失；DATA-08 导入导出与数据可迁移

### S23 · 隔离网络中静默部署后应用策略锁定

在无外网的计算机上用管理员的静默安装命令部署；然后下发一条锁定"自动更新"的策略；以普通用户身份登录使用。

检查点：安装未停在隐藏的对话框上，管理员获得了结果和失败原因；首次启动未要求联网下载运行时或激活；被锁定的设置显示了受管原因，用户的修改未显示为保存成功；配置写在普通用户自己的目录中。

相关条目：MANAGED-01 无人值守部署；MANAGED-02 用户与计算机范围；MANAGED-03 策略控制可见；MANAGED-04 隔离网络的完整路径；SETTINGS-05 作用域明确；INSTALL-03 更新偏好

### S24 · 扩展更新失败后恢复可用状态

安装若干扩展；让其中一个自动更新到不兼容的版本；然后将其停用、回退到旧版、卸载。

检查点：更新失败时主应用和其他扩展仍可使用；界面说明了是哪个扩展、何时更新；停用后其后台任务已停止，需要重启才生效时界面已说明；卸载未删除用户自己创建的内容；回退前提示了数据和设置的兼容性。

相关条目：EXTEND-02 来源与依赖可辨认；EXTEND-03 更新可控；EXTEND-04 停用与移除的影响；HELP-07 安全模式与自助恢复

### S25 · 无人值守批量转换，其中一个文件失败

通过命令行或脚本接口批量转换文件，输出到指定目录；其中一个文件已损坏；调用方按退出码判断结果；然后重新运行一次。

检查点：每个文件的成功或失败可通过退出码或结果文件判断，而不仅是输出文字；没有隐藏的对话框在等待操作；重新运行未将上一轮成功的输出重复生成；需要交互的步骤有文档说明。

### S26 · 搜索确实存在的对象却无结果
